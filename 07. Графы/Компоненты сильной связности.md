# Компоненты сильной связности

**Компонента сильной связности (SCC — Strongly Connected Component)** — максимальное подмножество вершин **ориентированного** графа, в котором из любой вершины достижима любая другая. Стянув каждую компоненту в одну вершину, получаем граф **конденсации** — это **DAG**, на котором корректно работают [[Топологическая сортировка]] и динамика.

* **Алгоритм Косараю:** два прохода DFS — сперва порядок завершения, потом обход обратного графа. $O(V + E)$, код простой.
* **Алгоритм Тарьяна:** один проход + стек, компактнее по константе, но хитрее в отладке.
* **Важное следствие:** если `x` и `y` в одной SCC — из `x` достижим `y` **и наоборот**; конденсация собирает «взаимную достижимость» в DAG.
* **Память:** два списка смежности (прямой и обратный) — $O(V + E)$.

## 🛠️ Идея (Косараю)

Первый DFS записывает порядок завершения вершин. Второй — бежит по **обратным** рёбрам в порядке, обратном завершению: каждый запуск обходит ровно одну SCC. Почему так: в «правильном» порядке конденсации вершины с минимальной «зависимостью» случайно оказываются последними в обратном обходе — обратные рёбра не дают выйти за пределы компоненты.

```cpp
#include <bits/stdc++.h>

using namespace std;

int V;
vector<vector<int>> g, gr;
vector<int> used, order, comp;

void dfs1(int v) {
    used[v] = 1;
    for (int to : g[v])
        if (!used[to]) dfs1(to);
    order.push_back(v);                        // завершили обработку — в конец
}

void dfs2(int v, int id) {
    comp[v] = id;
    for (int to : gr[v])
        if (comp[to] == -1) dfs2(to, id);
}

int main() {
    // …читаем V, рёбра: g — прямой граф, gr — обратный к нему…
    used.assign(V, 0);
    for (int v = 0; v < V; v++)
        if (!used[v]) dfs1(v);

    reverse(order.begin(), order.end());       // порядок «завершения», наоборот

    comp.assign(V, -1);
    int sccCount = 0;
    for (int v : order)
        if (comp[v] == -1) dfs2(v, sccCount++);

    cout << "Компонент: " << sccCount << "\n";
    for (int v = 0; v < V; v++) cout << "comp[" << v << "] = " << comp[v] << "\n";
}
```

* `comp[v]` — номер компоненты, `sccCount` — их количество.
* Список `order` **обязательно разворачивается** `reverse` — классическая ловушка Косараю.

## 💻 Конденсация

Стягиваем компоненты в вершины: дубли рёбер схлопываются, петли отбрасываются:

```cpp
vector<vector<int>> dag(sccCount);
for (int v = 0; v < V; v++)
    for (int to : g[v])
        if (comp[v] != comp[to])
            dag[comp[v]].push_back(comp[to]);  // ребро между разными компонентами

// антидубли (необязательно, но удобно для дальнейшего):
// sort + unique внутри dag[]
```

Получившийся `dag` **ацикличен** — на нём работают [[Топологическая сортировка]] и динамика. Причём сам порядок компонент из Косараю — уже обратный топопорядок.

## 🧮 2-SAT обзор

Задача: есть ли назначение булевым переменным, при котором формула в КНФ $\bigwedge (a \vee b)$ истинна. Сводка к SCC:

1. Для каждой переменной $x$ — две вершины: «$x$ истинно» и «$x$ ложно» ($\neg x$).
2. Дизъюнкция $(a \vee b)$ — две импликации: $\neg a \Rightarrow b$ и $\neg b \Rightarrow a$.
3. Решаемость: **есть** тогда и только тогда, когда $x$ и $\neg x$ лежат в **разных** SCC.
4. Само значение: если `comp[x] > comp[¬x]` (в порядке Косараю) — берём $x = $ истина, иначе ложь.

```cpp
// построить граф из пар (a, a_neg):
// add (~a -> b); add (~b -> a);   // для каждой дизъюнкции
// запустить Косараю → проверить, что comp[x] != comp[neg[x]] для всех x
```

2-SAT решается тем же Косараю без магии — SCC-механика + сравнение номеров компонент.

## 🧮 Где применяется

| Задача                                          | Приём                                     |
| :---------------------------------------------- | :---------------------------------------- |
| «Достижимы ли x и y друг из друга»              | одна SCC                                  |
| Сжатие графа для задач на «взаимно достижимое» | конденсация, $O(V + E)$                   |
| 2-SAT (назначение $a_i$ из дизъюнкций)         | Косараю + проверка `comp[x] != comp[¬x]` |
| Динамика на циклическом графе                  | конденсация → топосорт → ДП                |
| Проверка «нет циклов среди зависимостей»       | размеры SCC: если все единичные — DAG      |

## 🔍 Нюансы

* **Нужен обратный граф.** Косараю без `gr` не работает — его надо построить до обхода: читаем рёбра, пишем в оба списка.
* **Порядок компонент — сразу `reverse`-готовый топопорядок** — удобно для последующего ДП.
* **Тарьян** (один проход) экономит время/память обратного графа, но логика «стек + low» сложнее; на олимпиадах обычно достаточно Косараю по коду.
* **Конденсация с петлями:** петли внутри компоненты надо выкидывать (иначе DAG «зациклится»), для топосорта обязательны только уникальные рёбра.
* **2-SAT значения:** вариант `comp[x] > comp[¬x]` даёт корректный набор значений только при стандартном Косараю; при другом порядке обхода — инвертировать.
