# Мосты и точки сочленения

**Мост** — ребро, при удалении которого число компонент связности увеличивается. **Точка сочленения** — вершина, при удалении которой граф «рассыпается» на больше компонент. И то и другое ищется **одним DFS** за $O(V + E)$ с помощью меток `tin`/`low`.

* **`tin[v]`** — момент входа в вершину при обходе в глубину.
* **`low[v]`** — минимальный `tin`, достижимый из поддерева `v` по обычным и **обратным** рёбрам.
* **Мост `(v, to)`:** после обработки поддерева `to` выполняется `low[to] > tin[v]`.
* **Точка сочленения `v`:** не-корень — если `low[to] >= tin[v]` хоть для одного ребёнка; корень — если у него **≥ 2 детей** в DFS-дереве.
* **Сложность:** один проход, $O(V + E)$, память $O(V)$.

---

## 🛠️ Идея низких значений

В DFS-дереве у вершины есть «прямые» рёбра к детям и «обратные» — в сторону предков (их рисуем, когда сосед уже посещён). Обратное ребро «подтягивает» low поддерева вверх. Мост — ребро без обратной подстраховки: из поддерева `to` нельзя выбраться к предкам иначе, как через `(v, to)`. Точка сочленения — похожая идея, только без строгой «>`: если из поддерева нельзя «перескочить» **через `v`** к её предкам, удаление `v` отрезает это поддерево.

Типичные роли `tin`/`low`:

| Сравнение              | Что говорит                                          |
| :--------------------- | :--------------------------------------------------- |
| `low[to] > tin[v]`     | ребро `(v, to)` — мост                               |
| `low[to] >= tin[v]`    | вершина `v` отрезает поддерево `to` → точка сочленения |
| `low[v] == tin[v]`     | v — корень своего «блока»                            |

## 💻 Поиск мостов

```cpp
#include <iostream>
#include <vector>

using namespace std;

vector<int> tin, low, used;
int timer = 0;

void findBridges(int v, int p, const vector<vector<int>>& g) {
    used[v] = 1;
    tin[v] = low[v] = timer++;

    for (int to : g[v]) {
        if (to == p) continue;                 // обратный переход к родителю
        if (used[to]) {
            low[v] = min(low[v], tin[to]);     // обратное ребро — тянем low вверх
        } else {
            findBridges(to, v, g);
            low[v] = min(low[v], low[to]);
            if (low[to] > tin[v])              // поддерево не имеет других выходов
                cout << "Мост: " << v << " - " << to << "\n";
        }
    }
}
```

Точки сочленения — тот же обход, допиленный случаем корня:

```cpp
void findCut(int v, int p, const vector<vector<int>>& g, vector<int>& isCut) {
    used[v] = 1;
    tin[v] = low[v] = timer++;
    int children = 0;

    for (int to : g[v]) {
        if (to == p) continue;
        if (used[to]) {
            low[v] = min(low[v], tin[to]);
        } else {
            findCut(to, v, g, isCut);
            low[v] = min(low[v], low[to]);

            if (p != -1 && low[to] >= tin[v])  // не-корень: отрезает поддерево to
                isCut[v] = 1;
            children++;
        }
    }
    if (p == -1 && children > 1)               // корень: 2+ детей в DFS-дереве
        isCut[v] = 1;
}
```

* `p == -1` означает корень вызова — у него отдельное правило ($\ge 2$ детей).
* Ребро-мост и вершину-точку считаем одновременным проходом: `low[to] > tin[v]` для моста и `low[to] >= tin[v]` для точки — почти близнецы, легко перепутать.

## 🧮 Где применяется

| Задача                                              | Решение                                  |
| :-------------------------------------------------- | :--------------------------------------- |
| «Авария» на ребре — граф развалится?                | поиск мостов                              |
| «Уязвимые узлы» сети                                | точки сочленения                          |
| Двусвязные компоненты / блоки                        | развитие тех же `tin/low`                 |
| Один проход для раскраски «мост/не мост»            | `check`-флаговый DFS, $O(V + E)$          |
| Задача на минимальное число удалений для разрыва    | точки сочленения как «минимальный разрез через вершины» |

## 🔍 Нюансы

* **`>=` vs `>`:** для точек сочленения — `>=` (даже если обратное ребро уводит поддерево ровно в `v`, удаление `v` всё равно отрежет его); для мостов — строго `>`.
* **Корень ловим отдельно.** Правило «2 и более детей в DFS-дереве» применяется только к корню вызова.
* **Кратные рёбра.** Если между `u` и `v` два ребра — ни одно не мост. Отказ «пропускать родителя по номеру вершины» сломает подсчёт: надо запоминать **id ребра**, а не вершину-предка.
* **`low[v] = min(low[v], tin[to])` для посещённых** — именно `tin[to]`, а не `low[to]`: обратное ребро даёт «верхнюю точку», а не переносит низ полностью.
* **Глубокий граф** (цепочка на $10^6$ вершин) — рекурсивный DFS давит стек: итеративная версия или `#pragma comment(linker, ...)`/`ulimit`.
