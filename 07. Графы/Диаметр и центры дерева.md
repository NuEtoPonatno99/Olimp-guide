# Диаметр и центры дерева

**Диаметр дерева** — длина (в рёбрах) самого длинного пути между двумя вершинами. Его находят **двумя проходами** [[Обход BFS и DFS]]: из произвольной вершины до самой дальней $u$, затем из $u$ до самой дальней $v$ — путь $u$–$v$ и есть диаметр. **Центры дерева** — вершины «середины» этого ближайшего пути.

* **Алгоритм:** два BFS (или DFS) — $O(V)$, расстояние попутно; сам путь восстанавливается по предкам.
* **Центры:** середины диаметра, их **1 или 2**.
* **Радиус** дерева — минимальный эксцентриситет $\lceil D/2 \rceil$ (по рёбрам) — определяется центрами.
* **Не путать с центроидом** (балансировкой дерева) — другая вершина и другая формула!

---

## 🛠️ Идея

Ключевой факт: **самая дальняя вершина от любой вершины дерева — конец диаметра**. Поэтому:

1. запускаем BFS/DFS из произвольной вершины $s$, находим самую дальнюю $u$;
2. запускаем обход из $u$, находим самую дальнюю $v$;
3. путь $u$–$v$ — диаметр, его длина — ответ.

Центры — это средние вершины пути $u$–$v$: если длина чётная — один центр, если нечётная — два соседних.

## 💻 Два прохода

```cpp
#include <bits/stdc++.h>

using namespace std;

// пару раз: (самая дальняя вершина от start, расстояние до неё)
pair<int, int> farthest(int start, const vector<vector<int>>& g) {
    int n = g.size();
    vector<int> dist(n, -1);
    queue<int> q;
    dist[start] = 0;
    q.push(start);

    int far = start;
    while (!q.empty()) {
        int v = q.front();
        q.pop();
        for (int to : g[v])
            if (dist[to] == -1) {
                dist[to] = dist[v] + 1;
                q.push(to);
            }
    }
    for (int v = 0; v < n; v++)
        if (dist[v] > dist[far]) far = v;
    return {far, dist[far]};
}

int main() {
    // граф g — дерево (папин список смежности)…
    auto [u, d1] = farthest(0, g);
    auto [v, d2] = farthest(u, g);          // d2 — длина диаметра
    cout << "Диаметр = " << d2 << ", концы: " << u << " и " << v << "\n";
}
```

Если нужен **сам путь** — при обходе из $u$ заполняем `parent[to] = v`, затем идём от `v` к `u` по предкам.

### Центры

После восстановления пути от `u` до `v` (массив `path`):

```cpp
int D = d2;                                 // длина диаметра
int cnt = (int)path.size();                 // D + 1 вершин
vector<int> centers;
centers.push_back(path[cnt / 2]);           // всегда есть
if (cnt % 2 == 0)                           // середина попала между двух вершин
    centers.push_back(path[cnt / 2 - 1]);
```

## 🧮 Где применяется

| Задача                                            | Приём                                   |
| :------------------------------------------------ | :-------------------------------------- |
| Самая длинная «дорога» в сети                      | диаметр, $O(V)$                         |
| Минимизировать максимум расстояния до точки       | радиус = $O(D/2)$ через центр            |
| Центр обслуживания / маршруты «всех-ко-всем»      | центры дерева                           |
| Проверка «две вершины образуют диаметр»          | сравнение с парой (u, v)                 |
| «Покрыть дерево минимумом путей» и близкие        | диаметр как первая оценка                |

## 🔍 Нюансы

* **Только для деревьев.** На графах с циклами «два обхода» дают неверный результат — нужен другой аппарат.
* **Взвешенные рёбра:** два прохода работают для **неотрицательных** весов (обобщение той же идеи); при отрицательных — полный обход или ДП, не два BFS.
* **`BFS` из `s` в пустом графе** (одна вершина) — диаметр `0`, центр в ней самой.
* **Центроид ≠ центр.** Центр дерева — середина диаметра; центроид — вершина, отрезающая компоненты размером $\le n/2$. В задачах их часто путают — читать формулировку.
* **Путь через предков** при восстановлении: если хватает только длины — `dist[u]` уже даёт ответ без отдельного прохода.
