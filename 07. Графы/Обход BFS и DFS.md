# Обход BFS и DFS

**BFS (обход в ширину)** — обход графа «слоями» через очередь: сначала старт, потом его соседи, потом соседи соседей. За счёт этого в **невзвешенном** графе BFS находит кратчайшие пути от источника до всех вершин. **DFS (обход в глубину)** — рекурсивный «забег» вглубь до тупика. На DFS построены почти все продвинутые графовые алгоритмы: [[Мосты и точки сочленения]], [[Компоненты сильной связности]], [[LCA и двоичные подъёмы]], поиск циклов и топопорядка.

* **BFS:** очередь, метка «расстояние от старта». Находит кратчайший путь в невзвешенном графе за $O(V + E)$.
* **DFS:** рекурсия (или явный стек). Считает компоненты связности, циклы, топологический порядок — база для мостов, SCC, LCA.
* **0-1 BFS:** трюк с `deque` для рёбер веса $0/1$ — тот же линейный $O(V + E)$, без логарифма от [[Алгоритм Дейкстры]].
* **Память:** массив расстояний/цветов размера $V$ плюс хранение самого графа ([[Графы]]).

## 🛠️ BFS — очередь и слои

Кладём старт в очередь, помечаем `dist[start] = 0`. Достаём вершину, раскладываем по соседям ещё не посещённых (они ниже на 1 уровень). `dist[v]` — номер слоя, то есть **число рёбер** от старта.

```cpp
#include <iostream>
#include <vector>
#include <queue>

using namespace std;

void bfs(int start, const vector<vector<int>>& g) {
    vector<int> dist(g.size(), -1);          // -1 = ещё не посещена
    queue<int> q;
    dist[start] = 0;
    q.push(start);

    while (!q.empty()) {
        int v = q.front();
        q.pop();
        for (int to : g[v]) {
            if (dist[to] == -1) {            // первый раз — значит кратчайший путь
                dist[to] = dist[v] + 1;
                q.push(to);
            }
        }
    }
}
```

* Первое посещение вершины в BFS — гарантированно по кратчайшему пути, потому что очередь обрабатывает вершины строго по возрастанию слоя.
* `visited` тоже подходит (`bool`), но `dist[]` сразу даёт и расстояние.
* Для восстановления **пути** храним `parent[to] = v` и идём назад от цели.

## 💻 DFS — рекурсия в глубину

Заходим в вершину, помечаем, рекурсивно обходим всех непосещённых соседей. Один вызов обходит ровно одну компоненту связности:

```cpp
#include <iostream>
#include <vector>

using namespace std;

vector<int> used;

void dfs(int v, const vector<vector<int>>& g) {
    used[v] = 1;
    for (int to : g[v]) {
        if (!used[to]) dfs(to, g);
    }
}
```

Подсчёт компонент:

```cpp
int components = 0;
for (int v = 0; v < (int)g.size(); v++) {
    if (!used[v]) {
        dfs(v, g);
        components++;
    }
}
```

Тот же приём (заливка) работает и на «сеточных» графах — просто соседи это 4 клетки вокруг.

## 💻 0-1 BFS (рёбра веса 0 и 1)

Если веса только $0$ и $1$, обычный BFS не подходит (ребро веса $1$ ≠ уровня 1), а [[Алгоритм Дейкстры]] с кучей — «перебор». Трюк: держим `deque`. Пришли по ребру веса $0$ — кладём вершину **в начало**, по весу $1$ — **в конец**. Порядок извлечения остаётся по возрастанию расстояния — каждый обход по ребру один раз, $O(V + E)$.

```cpp
#include <iostream>
#include <vector>
#include <deque>

using namespace std;

const int INF = 1e9;

void bfs01(int start, const vector<vector<pair<int, int>>>& g) {
    vector<int> dist(g.size(), INF);
    deque<int> dq;                           // очередь с «двумя приоритетами»
    dist[start] = 0;
    dq.push_front(start);

    while (!dq.empty()) {
        int v = dq.front();
        dq.pop_front();
        for (auto [to, w] : g[v]) {
            if (dist[v] + w < dist[to]) {
                dist[to] = dist[v] + w;
                if (w == 0) dq.push_front(to);   // «дешёвое» ребро — в голову
                else        dq.push_back(to);    // ценой 1 — в хвост
            }
        }
    }
}
```

* Работает **только** для весов $\{0, 1\}$. Для весов $0..k$ с малым $k$ — обобщение (алгоритм Дейкстры на «ведрах»).
* Почему корректно: всё, что впереди — не дороже того, что в хвосте, поэтому дистанции достаются по возрастанию, как в обычном BFS.

## 🔄 Поиск циклов

### Неориентированный граф

В DFS передаём родителя. Встретили **уже посещённого** соседа, не являющегося родителем — есть обратное ребро, цикл найден:

```cpp
bool findCycle(int v, int p, const vector<vector<int>>& g, vector<int>& used) {
    used[v] = 1;
    for (int to : g[v]) {
        if (to == p) continue;               // ребро к родителю — не цикл
        if (used[to]) return true;           // обратное ребро → цикл
        if (findCycle(to, v, g, used)) return true;
    }
    return false;
}
```

### Ориентированный граф

Одного `used[bool]` мало — цикл через «зависшие» (серые) вершины. Три цвета: `0` не была, `1` в текущем стеке рекурсии, `2` полностью обработана:

```cpp
bool findCycleDir(int v, const vector<vector<int>>& g, vector<int>& color) {
    color[v] = 1;                            // вошли в стек
    for (int to : g[v]) {
        if (color[to] == 1) return true;     // ребро в «серую» — цикл
        if (color[to] == 0 && findCycleDir(to, g, color)) return true;
    }
    color[v] = 2;
    return false;
}
```

Тот же трёхцветный DFS — основа [[Топологическая сортировка]].

## 🧮 Где применяется

| Задача                                                | Приём                                        |
| :---------------------------------------------------- | :------------------------------------------- |
| Кратчайший путь в невзвешенном графе                  | BFS, слои                                     |
| Компоненты связности                                  | DFS-заливка, $O(V + E)$                       |
| Проверка двудольности                                 | BFS + чередование цвета вершин                |
| Поиск циклов (неориентированный / ориентированный)   | DFS с `parent` / трёхцветный DFS              |
| Кратчайший путь при весах $0/1$                       | 0-1 BFS                                       |
| База для [[Мосты и точки сочленения]], SCC, топосорта | один DFS + `tin/low`/цвета                    |

## 🔍 Нюансы

* **BFS в матрице** — заработает только $O(V^2)$, если «соседи» не списком, а перебором матрицы. Для плотных графов это нормально, для разреженных — [[Графы]]-список смежности.
* **`dist[to] == -1`** — проверка «первый раз». Перебор решения «уже была, но попробуем улучшить» превращает BFS в неэффективную модификацию.
* **Рекурсивный DFS** на глубине $10^6$ упирается в стек вызовов — либо поднять лимит стека, либо итеративно (явный `stack`).
* **0-1 BFS** ломается при отрицательных весах (любой BFS-семей), там только [[Алгоритм Беллмана — Форда]].
* **Двудольность:** если два соседа одного цвета — граф не двудольный; цикл нечётной длины равносилен «не двудольности».
