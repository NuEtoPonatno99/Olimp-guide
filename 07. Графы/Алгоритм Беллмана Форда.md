# Алгоритм Беллмана — Форда

**Алгоритм Беллмана — Форда** — это алгоритм поиска кратчайшего пути от **одной заданной вершины** до всех остальных. 

В отличие от алгоритма Дейкстры, он стабильно работает в графах, содержащих **отрицательные веса рёбер**.

* **Сложность по времени:** $O(V \times E)$, где $V$ — количество вершин, а $E$ — количество рёбер.
* **Главная фишка:** Умеет обнаруживать **циклы отрицательного веса** (когда можно бесконечно ходить по кругу и уменьшать расстояние до минус бесконечности).

---

## 🛠️ Как работает алгоритм: Принцип «Релаксации»

Алгоритм работает на основе списков рёбер. Он берёт массив расстояний и $V - 1$ раз пытается улучшить (релаксировать) каждый путь.

1. **Инициализация:** Расстояние до стартовой вершины ставится равным `0`, до всех остальных — «бесконечность» (`INF`).
2. **Основной цикл:** Повторяется ровно $V - 1$ раз. На каждой итерации мы перебираем **абсолютно все рёбра** графа.
3. **Релаксация:** Для каждого ребра, ведущего из вершины `u` в вершину `v` с весом `w`, проверяется условие:
   $$dist[v] = \min(dist[v], dist[u] + w)$$

## 💻 Базовая реализация на C++

Для этого алгоритма вместо тяжёлых матриц удобнее всего использовать структуру ребра `Edge`.

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

const int INF = 1e9; // Условная бесконечность

// Структура для хранения ребра графа
struct Edge {
    int from, to, weight;
};

void bellmanFord(int start, int V, int E, const vector<Edge>& edges) {
    vector<int> dist(V, INF);
    dist[start] = 0; // Расстояние до себя = 0

    // Шаг 1: Основной цикл релаксации (повторяем V - 1 раз)
    for (int i = 0; i < V - 1; i++) {
        for (int j = 0; j < E; j++) {
            int u = edges[j].from;
            int v = edges[j].to;
            int weight = edges[j].weight;
            
            // Если до вершины 'u' уже добрались, пытаемся улучшить путь до 'v'
            if (dist[u] != INF && dist[u] + weight < dist[v]) {
                dist[v] = dist[u] + weight;
            }
        }
    }

    // Шаг 2: Проверка на наличие циклов отрицательного веса
    // Если на V-й итерации путь всё ещё можно улучшить — значит в графе есть бесконечная петля уменьшения
    bool hasNegativeCycle = false;
    for (int j = 0; j < E; j++) {
        int u = edges[j].from;
        int v = edges[j].to;
        int weight = edges[j].weight;
        if (dist[u] != INF && dist[u] + weight < dist[v]) {
            hasNegativeCycle = true;
            break;
        }
    }

    // Вывод результатов
    if (hasNegativeCycle) {
        cout << "В графе обнаружен цикл отрицательного веса! Точный кратчайший путь найти нельзя." << endl;
    } else {
        cout << "Кратчайшие расстояния от вершины " << start << ":" << endl;
        for (int i = 0; i < V; i++) {
            if (dist[i] == INF) cout << "До вершины " << i << " нет пути" << endl;
            else cout << "До " << i << " = " << dist[i] << endl;
        }
    }
}

int main() {
    int V = 4; // Количество вершин
    int E = 4; // Количество ребер
    
    // Граф с отрицательным весом
    vector<Edge> edges = {
        {0, 1, 4},
        {0, 2, 5},
        {1, 2, -2}, // Ребро с отрицательным весом
        {2, 3, 3}
    };

    bellmanFord(0, V, E, edges);
    return 0;
}
```

## ⚖️ Сравнительный чеклист: Что выбрать?

| Критерий        | [[Алгоритм Флойда-Уоршелла]]                           | Беллман — Форд                 | [[Алгоритм Дейкстры]]                               |
| :-------------- | :----------------------------------------------------- | :----------------------------- | :-------------------------------------------------- |
| **Что ищет**    | Между **всеми** парами                                 | От **одной** до всех           | От **одной** до всех                                |
| **Сложность**   | Помедленнее: $O(V^3)$                                  | Средне: $O(V \times E)$        | Самый быстрый: $O(E \log V)$                        |
| **Отриц. веса** | ❌ Нельзя                                               | Можно                          | ❌ Нельзя                                            |
| **Когда брать** | Когда граф маленький и нужно знать вообще все маршруты | Когда есть отрицательные рёбра | Когда все веса положительные (ЕГЭ / классика такси) |
