# LCA и двоичные подъёмы

**LCA (Least Common Ancestor, наименьший общий предок)** для пары вершин дерева — самая глубокая вершина, являющаяся предком обеих. Классический способ — **двоичные подъёмы (binary lifting)**: предподсчёт $O(n \log n)$ и ответ на запрос за $O(\log n)$.

* **`up[v][k]`** — $2^k$-й предок вершины `v`; строится снизу вверх за $O(n \log n)$.
* **Запрос LCA:** выравниваем глубины, потом синхронно прыгаем по степеням двойки. $O(\log n)$.
* **Бонусы того же массива:** $k$-й предок, проверка «предок ли вершина», расстояние $dist(u,v) = depth[u] + depth[v] - 2 \cdot depth[lca]$ без самих путей.
* **Альтернативы:** Euler tour + [[Sparse Table (RMQ)]] (ответ за $O(1)$), Heavy-Light для «путевых» запросов.

---

## 🛠️ Идея

Любое число от $0$ до $n$ раскладывается по битам. Поэтому прыжок на произвольную высоту — серия прыжков на $2^k$. Значит, если умеем прыгать на $2^k$ предков для всех `k`, умеем прыгать на любой шаг:

* выровнять `u` и `v` по глубине;
* если после этого они совпали — `lca` найден;
* иначе прыгаем сверху вниз: с каждого уровня на $2^k$ предков, пока не упрёмся в общего выше — потом ещё один шаг вверх.

## 💻 Предподсчёт и LCA

```cpp
#include <bits/stdc++.h>

using namespace std;

const int LOG = 20;                         // 2^20 > 10^6 — хватит для большинства
vector<int> depth;
vector<vector<int>> up, g;                  // up[v][k] — 2^k-предок

void dfsLca(int v, int p) {
    up[v][0] = p;                           // 2^0 = 1-й предок — родитель
    for (int k = 1; k < LOG; k++)
        up[v][k] = up[ up[v][k-1] ][k-1];   // 2^k = 2^(k-1) + 2^(k-1)

    for (int to : g[v]) {
        if (to == p) continue;
        depth[to] = depth[v] + 1;
        dfsLca(to, v);
    }
}

int lca(int u, int v) {
    if (depth[u] < depth[v]) swap(u, v);

    int diff = depth[u] - depth[v];
    for (int k = 0; k < LOG; k++)            // поднимаем более глубокую на diff
        if (diff >> k & 1) u = up[u][k];

    if (u == v) return u;                    // один — предок другого

    for (int k = LOG - 1; k >= 0; k--)       // параметром «сверху вниз»
        if (up[u][k] != up[v][k])            // не совпали — можно смело прыгнуть
            u = up[u][k], v = up[v][k];

    return up[u][0];                         // ещё шаг — и это LCA
}
```

Способ вызова:

```cpp
depth[0] = 0;
dfsLca(0, 0);                                // корень — предок сам себе, up[root] = root
cout << lca(4, 5) << "\n";
```

* Корень делаем «сам себе предком» — `up[root][k] = root` навсегда; это упрощает граничные случаи.
* `diff >> k & 1` — «есть ли бит $2^k$ в разнице глубин».

## 💻 Применения двоичных подъёмов

$k$-й предок (вверх на $k$ рёбер):

```cpp
int kthAncestor(int v, int k) {
    for (int i = 0; i < LOG; i++)
        if (k >> i & 1) v = up[v][i];
    return v;
}
```

Расстояние между вершинами:

```cpp
int dist(int u, int v) {
    int w = lca(u, v);
    return depth[u] + depth[v] - 2 * depth[w];   // в рёбрах
}
```

Проверка «u — предок v» через `tin/tout` (можно видеть с `up`): в DFS запомнить «вход/выход» `tin[v]`, `tout[v]` — тогда `isAncestor(u, v) ⇔ tin[u] <= tin[v] && tout[v] <= tout[u]`.

Серия запросов «посчитать $f$ на пути `u–v`»: разбить путь на `u–lca` и `lca–v`, каждый — подъём с накоплением (храним в `up` ещё и агрегат пути).

## 🧮 Где применяется

| Задача                                                | Приём                                    |
| :---------------------------------------------------- | :--------------------------------------- |
| Расстояние между вершинами в дереве                    | $depth[u] + depth[v] - 2 depth[lca]$     |
| $k$-й предок / середина пути                          | подъём по битам, $O(\log n)$             |
| Проверка «предок ли», принадлежность поддереву        | `tin/tout` + DFS или `up`                 |
| Суммы/минимумы на пути                                | двоичные подъёмы с агрегатами в `up`      |
| LCA на каждом шаге добавления вершин (динамика)       | подъём, поддерживая `up` при до-пострении |

---

## 🔍 Нюансы

* **`LOG` должен быть $\ge \lceil \log_2 n \rceil + 1$.** Считается `while ((1 << LOG) <= n) LOG++`, либо `20`/`22` под константу задач. Меньше — выход за массив `up`.
* **Корень сам себе предок** — обязателен для `up[root][k]`; без этого `lca` на границах сломается.
* **Рекурсия `dfsLca`** на цепочке $10^6$ — переполнение стека; ускорять итеративным обходом.
* **Такой же массив решает и «прыжки кверху»**, а не только LCA — большинство задач на дереве решаются подъёмом.
* **Память:** `LOG` массивов по `n` — примерно `n * log n` (для $10^6$ это ~20 млн `int` ≈ 80 МБ) — следить за лимитами.
