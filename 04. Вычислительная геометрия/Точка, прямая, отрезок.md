# Точка, прямая, отрезок

**Точка** — пара координат $(x, y)$. **Прямая** на плоскости задаётся двумя точками или уравнением $ax + by + c = 0$. **Отрезок** — прямо с двумя концами. Всё в планиметрии сводится к знаку **векторного произведения** ([[Векторы]]) и к идее **$\varepsilon$-сравнения**.

* **Сложность операций:** $O(1)$ каждая.
* **Ключевой инструмент:** `cross(a, b)` — знак определяет «лево/право/на прямой».
* **Главный приём:** всегда сравнивать с $\varepsilon$, а не `==`.
* **Точка на прямой/отрезке/в треугольнике** — это проверка знаков и диапазонов.

---

## 🛠️ Идея

Точка принадлежит прямой — если `cross(b - a, p - a) == 0` (векторы коллинеарны). Точка на отрезке — если ещё и координаты между концами. Точка в треугольнике — три проверки «все повороты одинакового знака».

Но всё «\'равно нулю\'» из-за `double` ненадёжно, поэтому вводим точность:

$$\varepsilon = 10^{-9}, \qquad \text{`\=\`}\ \Leftrightarrow\ |x - y| < \varepsilon$$

```cpp
#include <iostream>
#include <cmath>

using namespace std;

const long double EPS = 1e-9;

struct Vector {
    long double x, y;
};

Vector operator-(const Vector& a, const Vector& b) {
    return {a.x - b.x, a.y - b.y};
}

long double cross(const Vector& a, const Vector& b) {
    return a.x * b.y - a.y * b.x;
}

long double dot(const Vector& a, const Vector& b) {
    return a.x * b.x + a.y * b.y;
}

bool eq(long double a, long double b) { return fabsl(a - b) < EPS; }
```

## 💻 Расстояние от точки до прямой и до отрезка

Расстояние до прямой — модуль векторного произведения делим на длину направляющего вектора. Это «высота» параллелограмма:

$$d = \frac{|(b - a) \times (p - a)|}{|b - a|}$$

Для отрезка результат — минимальное из трёх расстояний: до прямой (если проекция внутри отрезка) и до концов. Если проекция вне отрезка — берём ближайший конец:

```cpp
long double distToLine(const Vector& a, const Vector& b, const Vector& p) {
    Vector ab = b - a, ap = p - a;
    return fabsl(cross(ab, ap)) / sqrtl(dot(ab, ab));
}

long double distToSegment(const Vector& a, const Vector& b, const Vector& p) {
    Vector ab = b - a, ap = p - a, bp = p - b;
    // проекция выражена через скалярное произведение (косинус угла):
    // если проекция ab на ap лежит не между концами -> конец ближе
    if (dot(ab, ap) < 0)      return sqrtl(dot(ap, ap)); // у точки a
    if (dot(ab, bp) > 0)      return sqrtl(dot(bp, bp)); // у точки b
    return distToLine(a, b, p);
}
```

## 💻 Точка на отрезке (включая концы)

Точка $p$ на отрезке $[a, b]$: коллинеарность + $p$ внутри ограничивающего прямоугольника:

```cpp
bool onSegment(const Vector& a, const Vector& b, const Vector& p) {
    Vector ab = b - a, ap = p - a;
    if (!eq(cross(ab, ap), 0)) return false;          // не на прямой
    return min(a.x, b.x) - EPS <= p.x && p.x <= max(a.x, b.x) + EPS &&
           min(a.y, b.y) - EPS <= p.y && p.y <= max(a.y, b.y) + EPS;
}
```

## 💻 Пересечение отрезков

Классика из двух приёмов:

1. **Общая точка** — один из концов лежит на другом отрезке (проверяем `onSegment`).
2. **Пересечение «внутри»** — концы отрезков по разные стороны направляющей, и наоборот. Это две проверки знаков `cross`:

```cpp
bool intersect(const Vector& a, const Vector& b, const Vector& c, const Vector& d) {
    // ориентированные повороты: c и d относительно ab должны быть с разных сторон
    long double s1 = cross(b - a, c - a);
    long double s2 = cross(b - a, d - a);

    // один лежит на прямой другого — частный случай через onSegment
    if (s1 == 0 && onSegment(a, b, c)) return true;
    if (s2 == 0 && onSegment(a, b, d)) return true;

    // в 2D: векторы ab и cd не «разделяются» точками друг друга, если знаки противоположны
    if ((s1 > 0) == (s2 > 0)) return false;  // c и d — в одной полуплоскости относительно ab

    long double t1 = cross(d - c, a - c);
    long double t2 = cross(d - c, b - c);
    if ((t1 > 0) == (t2 > 0)) return false;  // и a,b — в одной полуплоскости относительно cd

    // осталось: точки по разные стороны -> отрезки пересекаются в одной точке
    return true; // (для точного поиска точки пересечения вместо знака нужно находить x,y)
}
```

> [!⚠️] Точка пересечения
> `intersect` сообщает **факт**. Если нужны координаты точки, найдите параметр на отрезке $ab$: $t = \frac{(c-a) \times (d-c)}{(b-a) \times (d-c)}$ (из пропорции площадей) — точка $p = a + (b - a) t$. Тот же приём деления отрезка в точке пересечения работает в любых «пересечениях в точке».

---

## 🔍 Нюансы

* **`== 0` с double не работает** — везде `eq`/$|x| < \varepsilon$. Иначе на огромных координатах потеряете пересечения.
* **Порядок точек в `cross`:** `cross(b - a, p - a) > 0` — `p` слева от направленного отрезка `a -> b`. Знак полностью определяет, «с какой стороны».
* **Вырожденные отрезки** (точка как отрезок) — отдельное ветвление: `distToSegment` и `intersect` на них должны давать определённый ответ; олимпиадные задачи редко это требуют, но проверять граничные случаи полезно.
* **Коллинеарные пересечения** — отрезки лежат на одной прямой и пересекаются по отрезку: объединяйте оба через `onSegment` вместо знаков.
