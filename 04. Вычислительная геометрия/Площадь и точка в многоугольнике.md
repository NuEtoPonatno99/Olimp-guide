# Площадь и точка в многоугольнике

**Площадь** простого (без самопересечений) многоугольника с вершинами $p_0, \dots, p_{n-1}$ считается одной формулой — **формулой Гаусса (шнурков)**. Проверка «лежит ли точка внутри» — двумя способами: через знаки `cross` для выпуклого и через луч для произвольного.

* **Сложность:** $O(n)$ на оба алгоритма.
* **Площадь:** $\frac{1}{2}\left|\sum_{i} p_i \times p_{i+1}\right|$.
* **Внутри**: для выпуклого — знаки `cross` одного направления; для любого — «число пересечений с лучом».»

---

## 🛠️ Идея: формула Гаусса (шнурков)

Площадь многоугольника — это сумма «знаковых площадей» треугольников из начальной точки $p_0$:

$$\text{S} = \frac{1}{2}\left|\sum_{i=0}^{n-1} p_i \times p_{i+1}\right|, \qquad p_n = p_0$$

Каждое слагаемое — `cross(p_i, p_{i+1})`, удвоенная знаковая площадь треугольников $p_0 p_i p_{i+1}$. Отрицательные (по часовой стрелке) части сокращаются с положительными — остаётся ровно площадь многоугольника. Знак итога сам говорит, по часовой ли стрелке обход (положительный — против часовой).

```cpp
#include <iostream>
#include <vector>
#include <cmath>

using namespace std;

struct Point {
    long double x, y;
};

long double cross(const Point& a, const Point& b) {
    return a.x * b.y - a.y * b.x;
}

long double polygonArea(const vector<Point>& p) {
    long double sum = 0;
    int n = (int)p.size();
    for (int i = 0; i < n; i++) {
        sum += cross(p[i], p[(i + 1) % n]); // знаковая площадь
    }
    return fabsl(sum) / 2.0;
}
```

* Формула «сама по себе» не требует координат замыкания — берёте `p[i+1]` по кругу (последняя с первой).
* Знак суммы — направление обхода: `> 0` — против часовой, `< 0` — по часовой.

## 💻 Точка в выпуклом многоугольнике

Если многоугольник **выпуклый** и вершины заданы против часовой стрелки, точка внутри $\iff$ для всех рёбер выполняется `cross(edge, p - v) >= 0` (поворот «налево»). Это проверка «точка по левую сторону от каждого ребра»:

```cpp
bool pointInConvex(const vector<Point>& p, const Point& q) {
    int n = (int)p.size();
    for (int i = 0; i < n; i++) {
        Point a = p[i], b = p[(i + 1) % n];
        if (cross(b - a, q - a) < 0)   // справа хотя бы от одного ребра -> вне
            return false;
    }
    return true;
}
```

> [!⚠️] Порядок обхода важен!
> Если вершины **по часовой** — инвертируйте знак (условие `<= 0`). Удобно приводить обход к стандартному с помощью `polygonArea`: если площадь отрицательна — развернуть массив.

## 💻 Точка в произвольном (невыпуклом) многоугольнике

Для любого многоугольника используем **метод луча**: пускаем горизонтальный луч вправо от точки и считаем пересечения с рёбрами. Внутри — если число пересечений **нечётное**.

```cpp
bool pointInPolygon(const vector<Point>& p, const Point& q) {
    int n = (int)p.size();
    bool inside = false;
    for (int i = 0, j = n - 1; i < n; j = i++) {
        Point a = p[i], b = p[j];
        // вершины по разные стороны от горизонтали точки
        if ((a.y > q.y) != (b.y > q.y)) {
            // x пересечения луча с ребром ab
            long double xint = a.x + (q.y - a.y) / (b.y - a.y) * (b.x - a.x);
            if (q.x < xint) inside = !inside; // пересечение справа от точки
        }
    }
    return inside;
}
```

* Луч берём **горизонтальный вправо**, поэтому нас интересуют пересечения только с $x > q.x$.
* Вырожденные случаи (точка на границе) классически обрабатываются отдельно — обычно просят «внутри или на границе», тогда проверяйте `onSegment`.

## 🔍 Нюансы

* **Знаковые площади**, а не модуль: отрицательные «дыры» (многоугольник буквой «C») вычитаются автоматически, если в массиве хранить идёшь против часовой — это отдельный разговор про «вырезание дыр».
* **`cross` с огромными координатами** — `long double`.
* **Точка на границе в `pointInPolygon`:** метод луча даёт неопределённость на ребре. Стандартный трюк: сначала проверить `onSegment` по всем рёбрам, затем уже `inside`.
* **Формула Гаусса даёт площадь за $O(n)$** и не требует сортировки — главный конкурент «триангуляции» из школьной геометрии.
* **Направление обхода**: одно из следствий формулы — по знаку `sum` узнаёте порядок, что нужно в [[Выпуклая оболочка]].
