# Векторы

**Вектор** — главный кирпич вычислительной геометрии: это направленный отрезок (перемещение) из точки $A$ в точку $B$. Задача точки $p(x, y)$ вместо этого хранит «радиус-вектор» $\vec{p} = (x, y)$ — все операции над точками и векторами одинаковы.

* **Сложность операций:** $O(1)$ каждая.
* **Два главных произведения:** скалярное (число: косинус угла) и векторное (знак/двойная площадь: «лево–право»).
* **Вектор между точками:** $\vec{AB} = B - A$ (покоординатно).
* **Равенство/сумма/длина:** покоординатно; $|\vec{a}| = \sqrt{a_x^2 + a_y^2}$.

---

## 🛠️ Идея

Над точками работаем покоординатно, как над парами чисел. Вектор из точки $a$ в точку $b$: `b - a` покоординатно. Умножение вектора на константу — масштабирование. Длина — теорема Пифагора.

Самое важное — **две «машинки» вычислений**, которыми считается почти вся геометрия:

* **Скалярное произведение** $\vec{a} \cdot \vec{b} = a_x b_x + a_y b_y = |\vec{a}||\vec{b}|\cos\varphi$ — говорит о **косинусе угла** и о **длинах проекций**, не создавая нулевых длин.
* **Векторное (косое) произведение** (на плоскости, в 2D) — «псевдоскаляр»:
  $$a \times b = a_x b_y - a_y b_x = |\vec{a}||\vec{b}|\sin\varphi$$
  Знак показывает, **с какой стороны** второй вектор относительно первого («лево» — положительное, «право» — отрицательное), а модуль равен **удвоенной площади** параллелограмма. В 3D векторное произведение — настоящий вектор, но в олимпиадных задачах обычно 2D.

## 💻 Реализация

```cpp
#include <iostream>
#include <cmath>

using namespace std;

struct Vector {
    long double x, y;

    Vector operator+(const Vector& o) const { return {x + o.x, y + o.y}; }
    Vector operator-(const Vector& o) const { return {x - o.x, y - o.y}; }
    Vector operator*(long double k)   const { return {x * k, y * k}; }
    long double length() const { return sqrtl(x * x + y * y); }
};

// Скалярное произведение: |a||b|cos(phi), число
long double dot(const Vector& a, const Vector& b) {
    return a.x * b.x + a.y * b.y;
}

// Векторное (косое) произведение в 2D:
// знак — с какой стороны b от a, модуль — 2*площадь треугольника (a, 0, b)
long double cross(const Vector& a, const Vector& b) {
    return a.x * b.y - a.y * b.x;
}

int main() {
    Vector a = {1, 2};
    Vector b = {4, 6};
    cout << dot(a, b) << endl;     // 1*4 + 2*6 = 16
    cout << cross(a, b) << endl;   // 1*6 - 2*4 = -2  ->  b лежит справа от a
    return 0;
}
```

* `cross` считается **знаковым** — в отрыве от модуля он говорит «лево/право»; модуль — площадь параллелограмма.
* Для чистых задач на знак разумно брать `long long`: координаты чаще целые, а точность знака важнее десятичной.

## 🧮 Когда какое произведение

| Вопрос                                         | Инструмент                     | Что считать                        |
| :--------------------------------------------- | :----------------------------- | :--------------------------------- |
| Угол между векторами острый/тупой/прямой       | скалярное                      | знак `dot`                        |
| Поворот «налево/направо»                        | векторное                      | знак `cross`                       |
| Площадь треугольника / параллелограмма         | векторное                      | $\frac{1}{2}|\text{cross}|$ / $|\text{cross}|$ |
| Проекция одного вектора на другой              | скалярное                      | $\frac{a \cdot b}{|b|}$            |
| Длина и расстояние $|AB|$                      | «скалярное квадрат»               | $\sqrt{a \cdot a}$                 |

## 🔍 Нюансы

* **Равенство векторов/точек:** из-за `double` никогда не сравнивайте `==`; сравнивайте расстояние $< \varepsilon$.
* **Знак `cross` — источник всего:** от него зависит «левее/правее» в [[Точка, прямая, отрезок]], попадание точки в треугольник, порядок обхода и [[Выпуклая оболочка]].
* **Векторное произведение в 2D — не совсем вектор:** это число, поэтому «перемножать» два вектора местами меняет знак (антикоммутативность).
* **Переполнение:** при больших координатах `a.x * b.y` легко выходит за `int` — берите `long long`/`long double`.
* **В 3D** (редкие задачи) векторное произведение — настоящий вектор $a \times b = (a_y b_z - a_z b_y, a_z b_x - a_x b_z, a_x b_y - a_y b_x)$, а скалярное — как в 2D, но с третьей координатой.
