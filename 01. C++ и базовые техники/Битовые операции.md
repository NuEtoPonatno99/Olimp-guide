# Битовые операции и битовые маски

**Битовые операции** работают с целыми числами на уровне отдельных битов. На олимпиадах они незаменимы для **битовых масок** — представления подмножества множества через биты числа.

* **Зачем:** упаковка состояния «какие элементы выбраны» в одно `int` (до 32 элементов) или `long long` (до 64), компактное хранение таблиц, перебор подмножеств.
* **Скорость:** все операции выполняются за $O(1)$ на уровне процессора.

---

## 🛠️ Операторы

| Оператор      | Название          | Действие                                | Пример (`x = 0b1010`) |
| :------------ | :---------------- | :-------------------------------------- | :-------------------- |
| `&`           | И (AND)           | Бит = 1, если оба бита = 1              | `x & 1 == 0`          |
| `\|`          | ИЛИ (OR)          | Бит = 1, если хотя бы один бит = 1      | `x \| 5`              |
| `^`           | XOR (искл. ИЛИ)   | Бит = 1, если биты разные               | `x ^ x == 0`          |
| `~`           | НЕ (инверсия)     | Все биты инвертируются                  | `~x`                  |
| `<<`          | Сдвиг влево       | Умножение на $2^k$: `x << k`            | `1 << 4 == 16`        |
| `>>`          | Сдвиг вправо      | Деление на $2^k$: `x >> k`              | `x >> 1`              |

**Ключевые свойства XOR:**
$$a \oplus a = 0, \quad a \oplus 0 = a$$

Это даёт красивый трюк: если XOR-ить все элементы массива, парные элементы взаимно уничтожатся, и останется число, встречающееся **нечётное** число раз.

## 🧮 Базовые действия с масками

Маска $mask$ — это `int`, где $i$-й бит означает «элемент $i$ входит в подмножество».

| Операция                          | Код                         |
| :-------------------------------- | :-------------------------- |
| Включить бит $i$                  | `mask |= (1 << i)`          |
| Выключить бит $i$                 | `mask &= ~(1 << i)`         |
| Инвертировать бит $i$             | `mask ^= (1 << i)`          |
| Проверить, стоит ли бит $i$       | `mask & (1 << i)`           |
| Пустое подмножество               | `0`                         |
| Полное подмножество из $n$        | `(1 << n) - 1`              |
| Младший единичный бит             | `mask & (-mask)`            |
| Число единичных битов             | `__builtin_popcount(mask)`  |

**Трюк со степенью двойки:** число $n$ — степень двойки, тогда и только тогда, когда:
$$n > 0 \quad\text{и}\quad n \,\&\, (n-1) = 0$$

**Перебор всех подмасок** данной маски за $O(2^k)$ (для каждой подмаски):
```cpp
void iterateSubmasks(int mask) {
    for (int s = mask; s; s = (s - 1) & mask) {
        // s — очередное подмножество mask (непустое)
        // process(s);
    }
    // Не забудьте про пустое подмножество 0 — оно обрабатывается отдельно
}

int main() {
    iterateSubmasks(0b110); // подмножества множества {1, 2}: 2, 4, 6
    return 0;
}
```
```
Перебор ВСЕХ подмножеств всех масок суммарно занимает $O(3^n)$ — это база для [[ДП по подмножествам (битмаски)]].

## 💻 Встроенные функции GCC (`__builtin_*`)

Для `int` и `long long` (суффикс `ll`):

| Функция                      | Возвращает                          |
| :--------------------------- | :---------------------------------- |
| `__builtin_popcount(x)`      | Число единичных битов               |
| `__builtin_ctz(x)`           | Число нулей в конце (`count trailing zeros`) |
| `__builtin_clz(x)`           | Число нулей в начале               |
| `__builtin_ffs(x)`           | Позиция младшего единичного бита (с 1) |

> [!⚠️] Undefined behavior
> `ctz(0)` и `clz(0)` — **неопределённое поведение**. Перед вызовом проверяйте `x != 0`.

## 💻 Пример: три типовые задачи в одной программе

```cpp
#include <iostream>

using namespace std;

// 1) Число, встречающееся нечётное число раз — фокус с XOR
int oddOccurrence(int arr[], int n) {
    int x = 0;
    for (int i = 0; i < n; i++) x ^= arr[i];
    return x;
}

// 2) Перебор всех подмножеств множества {0, 1, ..., n-1} с подсчётом суммы
int sumOfAllSubsetSums(int a[], int n) {
    int total = 0;
    for (int mask = 0; mask < (1 << n); mask++) {
        for (int i = 0; i < n; i++) {
            if (mask & (1 << i)) total += a[i]; // элемент i включён в mask
        }
    }
    return total;
}

int main() {
    // Задача 1: одно число повторяется нечётно
    int a[] = {4, 1, 4, 2, 1, 4, 2};
    int n = sizeof(a) / sizeof(a[0]);
    cout << "Нечётное: " << oddOccurrence(a, n) << endl; // 4

    // Задача 2: подмножества
    int b[] = {1, 2, 3};
    cout << "Сумма всех сумм подмножеств {1,2,3}: " << sumOfAllSubsetSums(b, 3) << endl;

    // Задача 3: проверка степени двойки
    for (int x : {1, 2, 3, 4, 8, 12, 16, 64}) {
        bool ok = (x > 0) && ((x & (x - 1)) == 0);
        cout << x << " -> " << (ok ? "степень двойки" : "нет") << endl;
    }

    return 0;
}
```
```
// Нечётное: 4
// Сумма всех сумм подмножеств {1,2,3}: 24
// ...
```

## 🔍 Нюансы

* **Переполнение при сдвиге:** `1 << 31` уже не влезает в знаковый `int` правильно. Для 32+ битов используйте `1LL << k` или `uint32_t`/`uint64_t`.
* **Приоритет операторов:** `&` и `|` имеют низкий приоритет — всегда оборачивайте выражения в скобки: `if ((mask & (1 << i)) != 0)`.
* **Отрицательные числа:** битовые операции с ними ведут себя через дополнительный код — маски обычно стараются делать `unsigned`.
* **Маска-состояние в ДП:** размер памяти для ДП по битмаскам — $O(2^n)$, поэтому $n$ больше 20–22 уже тяжко.

> [!💡] Связки
> Битовые маски — фундамент для [[ДП по подмножествам (битмаски)]] и часто появляются в задачах на [[Рекурсия и перебор]]. Перебор подмасок за $O(3^n)$ — стандартный приём в задачах на разбиения.
