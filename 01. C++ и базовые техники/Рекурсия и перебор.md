# Рекурсия и перебор (Backtracking)

**Перебор (полный перебор, backtracking)** — метод решения, при котором программа систематически проходит все варианты решения. Он медленный, но простой и часто является **единственным** способом для небольших ограничений ($n \le 20$).

* **Сложность:** перебор всех подмножеств — $O(2^n)$, всех перестановок — $O(n!)$, перебор с возвратом умнее полного.
* **Когда использовать:** когда $n$ маленькое, или когда перебор — единственный гарантированный способ и его можно ускорить отсечениями.

---

## 🛠️ Идея (Backtracking)

Мы строим решение **пошагово**: на каждом шаге пробуем все допустимые варианты продолжения. Если текущая ветка зашла в тупик — **откатываемся** (backtrack) к предыдущему шагу и пробуем следующий вариант.

Ключевые элементы рекурсивной процедуры:

1. **Параметры состояния** — что уже построено (номер шага, частичный результат, занятые клетки).
2. **База рекурсии** — когда решение полное: зафиксировать результат.
3. **Отсечения** — проверка, что текущую ветку можно продолжить (иначе сразу выйти).
4. **Восстановление состояния** — отменить сделанный ход перед возвратом.

Псевдокод (передан на русском, чтобы отразить логику, а не синтаксис):
```
void rec(int step) {
    if (step == N) { обработать_готовое_решение(); return; }
    for (вариант допускается) {
        если (вариант_валиден(step)) {
            пометить(step);   // сделать ход
            rec(step + 1);    // углубиться
            снять_метку(step); // откат!
        }
    }
}
```

## 💻 Пример: расстановка $N$ ферзей

Классика перебора. Ферзи не должны бить друг друга: не делят строку, столбец и диагональ. Перебираем строки, в каждой ставим ферзя в свободную колонку, проверяя занятость диагоналей за $O(1)$.

--- Полностью компилируемая программа: ---

```cpp
#include <iostream>

using namespace std;

int n;
int ans = 0;
bool col[20];      // занятые столбцы
bool diag1[40];    // диагонали вида r + c
bool diag2[40];    // диагонали вида r - c + n

void placeQueens(int row) {
    if (row == n) {        // Все N ферзей расставлены — это решение
        ans++;
        return;
    }
    for (int c = 0; c < n; c++) {
        // Ферзь бьёт по столбцу и двум диагоналям
        if (col[c] || diag1[row + c] || diag2[row - c + n]) continue;

        col[c] = diag1[row + c] = diag2[row - c + n] = true;
        placeQueens(row + 1);
        col[c] = diag1[row + c] = diag2[row - c + n] = false; // откат!
    }
}

int main() {
    cin >> n;
    placeQueens(0);
    cout << "Решений: " << ans << endl;
    return 0;
}
```

* Идея диагоналей: у клеток одной диагонали **одинаковая** сумма `r + c` или **одинаковая** разность `r - c`. Это превращает проверку из $O(n)$ в $O(1)$.
* Откат (строки с `= false`) обязателен: без него все ветки «переносят» запреты в чужие решения.

## 🧮 Оценка и ускорение перебора

| Параметр        | Количество вариантов                        | Реально?                    |
| :-------------- | :------------------------------------------ | :-------------------------- |
| $n$ подмножеств | $2^n$                                       | $n \le 25$ с оптимизацией  |
| $n!$ перестановок | $n!$                                      | $n \le 10$ − 11             |
| Шахматная доска | Ферзи: $O(n!)$ в худшем, отсечения рулят     | $n \le 20$−30               |

**Как ускорить:**
1. **Сортировка и жадный порядок:** перебирайте самые «ветвистые» варианты первыми (часто сначала сортируют данные).
2. **Предподсчёт:** проверки за $O(1)$ вместо циклов (как диагонали у ферзей).
3. **Симметрия:** если задача симметрична, уменьшаем перебор вдвое (первую позицию ферзя — только в половину доски).
4. **Верхняя/нижняя оценка:** если текущая ветка уже не может дать лучший результат, чем найденный — режем.

## 💻 Рекурсивные генерации: сочетания и перестановки

Если рекурсия не нужна, а нужна просто генерация — STL уже всё умеет:

```cpp
#include <iostream>
#include <algorithm>
#include <vector>

using namespace std;

int main() {
    // 1) Все перестановки
    int p[] = {1, 2, 3};
    do {
        for (int x : p) cout << x;
        cout << " ";
    } while (next_permutation(p, p + 3));
    cout << endl;

    // 2) Все сочетания по k из n: заполняем массив единицами/нулями длины n (не газ, а вектор сочетаний)
    //    Схема: {0,...,0,1,...,1} и next_permutation даёт все позиции k единиц
    int n = 5, k = 2;
    vector<int> comb(n, 0);
    fill(comb.end() - k, comb.end(), 1); // k единиц в конце
    do {
        // позиции единиц — это и есть сочетание из k элементов
    } while (next_permutation(comb.begin(), comb.end()));

    return 0;
}
```

> [!⚠️] Глубина рекурсии
> Стандартный стек C++ держит ~$10^5$–$10^6$ вызовов, потом переполнение. Если рекурсия глубокая — либо увеличивайте стек, либо переписывайте итеративно. Для задач с $n=10^6$ рекурсивный перебор принципиально невозможен.

## 🔍 Нюансы

* **Мемоизация граничит с ДП:** если вы перебираете одно и то же состояние многократно — это уже [[Динамическое программирование. Основы]].
* **Перебор — основа многих идей:** [[Встреча посередине (Meet-in-the-Middle)]] делит задачу и перебирает две половины за $2^{n/2}$ вместо $2^n$.
* **Метод отсечений** — единственный способ вытащить перебор там, где $n$ чуть-чуть больше обычного.
