# Префиксные суммы и разности

**Префиксные суммы** позволяют отвечать на запросы «сумма на подотрезке» за $O(1)$ после $O(n)$ предподсчёта. **Разностный массив** — обратная операция: быстрые прибавления $x$ на отрезке сразу во всех элементах.

* **Сложность предподсчёта:** $O(n)$ (в 2D — $O(n \times m)$).
* **Сложность запроса:** $O(1)$.
* Это **база для огромного числа олимпиадных задач**: без неё не решается половина задач на массивы.

---

## 🛠️ Одномерные префиксные суммы

Пусть есть массив $a[0..n-1]$. Строим массив `pref`:

$$pref[i] = \sum_{k=0}^{i-1} a[k], \qquad pref[0] = 0$$

Тогда сумма на подотрезке $[l, r]$ (включительно) вычисляется вычитанием:

$$sum(l, r) = pref[r+1] - pref[l]$$

```cpp
#include <iostream>
#include <vector>

using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];

    // pref[i] = сумма первых i элементов: pref[0]=0, pref[i+1]=pref[i]+a[i]
    vector<long long> pref(n + 1, 0);
    for (int i = 0; i < n; i++)
        pref[i + 1] = pref[i] + a[i];

    // Произвольные запросы: сумма на [l, r]
    int q;
    cin >> q;
    while (q--) {
        int l, r;
        cin >> l >> r;              // 0-индексация, включительно
        cout << pref[r + 1] - pref[l] << endl; // O(1)!
    }
    return 0;
}
```

Размер массива `n + 1` и полуинтервалы `[0, n]` — **стандарт**, избавляет от ветвлений на границах.

## 💻 Разностный массив (блочные прибавления)

Задача: дано много операций «прибавить $x$ ко всем элементам на $[l, r]$», в конце вывести массив. Пусть $d$ — разностный массив (длины $n+1$):

* Прибавление на $[l, r]$ → `d[l] += x; d[r + 1] -= x;`
* После всех операций массив восстанавливается префиксными суммами $d$, т.е. $a[i] = pref\_d[i+1]$.

Интуиция: `d[l] += x` включает «факел», `d[r+1] -= x` его гасит. Префиксные суммы проносят факел по массиву.

```cpp
#include <iostream>
#include <vector>

using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<long long> d(n + 1, 0); // разностный массив

    while (m--) {
        int l, r;
        long long x;
        cin >> l >> r >> x; // прибавить x на [l, r]
        d[l] += x;
        d[r + 1] -= x;
    }

    // Восстановление массива через префиксные суммы d
    long long cur = 0;
    for (int i = 0; i < n; i++) {
        cur += d[i];
        cout << cur << " ";
    }
    cout << endl;
    return 0;
}
```

**Асимптотика:** $O(n + m)$ вместо наивных $O(n \times m)$. Разрыв огромный при большом $m$.

## 🧮 Двумерные префиксные суммы

Для суммы в прямоугольнике $O(1)$ после предподсчёта $O(n \times m)$:

$$pref[i+1][j+1] = pref[i][j+1] + pref[i+1][j] - pref[i][j] + a[i][j]$$

$$sum(x_1, y_1, x_2, y_2) = pref[x_2+1][y_2+1] - pref[x_1][y_2+1] - pref[x_2+1][y_1] + pref[x_1][y_1]$$

Формула прямоугольника — включение-исключение (в клетку, между $(x_1,y_1)$ и $(x_2,y_2)$):

```cpp
// Пример матрицы 3x3 и запрос суммы прямоугольника [x1..x2] x [y1..y2]
#include <iostream>
#include <vector>

using namespace std;

int main() {
    int n = 3, m = 3;
    vector<vector<int>> a = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}};

    vector<vector<int>> pref(n + 1, vector<int>(m + 1, 0));
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            pref[i + 1][j + 1] = pref[i][j + 1] + pref[i + 1][j] - pref[i][j] + a[i][j];

    auto rect = [&](int x1, int y1, int x2, int y2) {
        return pref[x2 + 1][y2 + 1] - pref[x1][y2 + 1] - pref[x2 + 1][y1] + pref[x1][y1];
    };

    cout << "Сумма всего поля: " << rect(0, 0, 2, 2) << endl; // 45
    cout << "Сумма центра (5): " << rect(1, 1, 1, 1) << endl; // 1x1
    return 0;
}
```

## 💻 Двумерный разностный массив

Прибавить $x$ к прямоугольнику $(x_1,y_1)$–$(x_2,y_2)$ одной операцией — **4 точки** в разностной матрице:

$$d[x_1][y_1] += x; \quad d[x_1][y_2+1] -= x; \quad d[x_2+1][y_1] -= x; \quad d[x_2+1][y_2+1] += x;$$

Затем восстанавливаем двумерными префиксными суммами. Это решает задачи вроде «параллельные прямоугольные покраски» за $O(n^2 + m)$.

## 🔍 Где применяется и нюансы

| Задача                                        | Решение через                                      |
| :-------------------------------------------- | :------------------------------------------------- |
| Сумма на подотрезке, много запросов           | 1D префиксные суммы                                |
| Прибавление на отрезке                        | Разностный массив                                  |
| Сумма в прямоугольнике                        | 2D префиксные суммы                                |
| Равные подмассивы / подмассив с суммой 0      | Хэш карта + префиксные суммы                       |
| Число подмассивов с суммой ≤ S                | [[Два указателя]] + префиксы                       |
| Средняя температура/количество в окне         | Префиксы + (два указателя)                         |

* **Переполнение:** суммы растут быстро — берите `long long`.
* **Совместимость с [[Бинарный поиск]]:** проверка «сумма/условие на подотрезке» за $O(1)$ — основа бинарного поиска «по ответу» на задачах про окна.
* **Префиксный XOR** — аналог для XOR-задач: `prefXor[i]` строится так же, `subsegment ^ = prefXor[r+1] ^ prefXor[l]`.

> [!⚠️] Префиксные суммы — НЕ хранение всего
> У префиксных сумм $O(n)$ памяти. Если нужно менять массив и спрашивать суммы динамически — это уже [[Дерево Фенвика]] или [[Дерево отрезков]].
