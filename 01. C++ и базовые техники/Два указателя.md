# Два указателя (Two Pointers)

**Метод двух указателей** решает задачи про подмассивы и пары элементов за **один проход** ($O(n)$) вместо $O(n^2)$. Идея: два индекса движутся **только вперёд**, поэтому суммарно каждый проходит массив не больше раза.

* **Сложность по времени:** $O(n)$.
* **Память:** $O(1)$ дополнительно (кроме запросов).
* **Ключевое условие применения:** монотонность — расширение окна не портит выполненное условие, сужение — не создаёт новых возможностей.

---

## 🛠️ Классика: минимальная длина подмассива с суммой ≥ S

Идём правым указателем $r$, расширяя окно. Когда условие выполнено — пытаемся ужать слева указателем $l$, фиксируя длину окна.

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int shortestSubarrayWithSum(const vector<int>& a, long long S) {
    int n = (int)a.size();
    long long sum = 0;
    int best = n + 1; // «бесконечность»
    int l = 0;

    for (int r = 0; r < n; r++) {
        sum += a[r];                // расширяем окно вправо

        while (sum - a[l] >= S) {   // можно ли убрать a[l], сохранив условие?
            sum -= a[l];
            l++;                    // если да — убираем (l двигается вперёд!)
        }

        if (sum >= S) best = min(best, r - l + 1);
    }
    return best > n ? -1 : best;    // -1, если такого подмассива нет
}

int main() {
    vector<int> a = {2, 3, 1, 2, 4, 3};
    long long S = 7;
    // Ответ: [4, 3] длина 2
    cout << "Минимальная длина: " << shortestSubarrayWithSum(a, S) << endl;
    return 0;
}
```

* $l$ и $r$ **никогда не идут назад** — поэтому суммарно $O(n)$.
* Здесь условие «сумма ≥ S» монотонно по расширению окна: чем больше окно, тем «проще» выполнить условие.

## 💻 Подсчёт количества «хороших» подмассивов

Распространённая вариация: посчитать, **сколько** подмассивов удовлетворяют условию. Приём: для фиксированного $r$ все корректные левые границы образуют отрезок $[0..l]$; каждый такой $l$ даёт один подмассив.

Задача: посчитать количество подмассивов с суммой **≤ S**.

```cpp
#include <iostream>
#include <vector>

using namespace std;

long long countSubarraysSumAtMost(const vector<int>& a, long long S) {
    long long cnt = 0;
    long long sum = 0;
    int l = 0, n = (int)a.size();

    for (int r = 0; r < n; r++) {
        sum += a[r];
        while (sum > S) {   // восстанавливаем условие: тянем l вперёд
            sum -= a[l];
            l++;
        }
        // Все подмассивы, заканчивающиеся в r и начинающиеся в [l..r] — подходят
        cnt += r - l + 1;
    }
    return cnt;
}

int main() {
    vector<int> a = {1, 2, 3};
    cout << countSubarraysSumAtMost(a, 4) << endl; // [1],[2],[3],[1,2] => 4
    return 0;
}
```

Ключевая формула: `cnt += r - l + 1`. Каждый новый правый конец добавляет ровно `(r - l + 1)` новых подмассивов с суммой ≤ S.

## 💻 Слияние двух отсортированных массивов (не сливать вручную!)

Классический алгоритм `merge` — тоже метод двух указателей. STL уже даёт `std::merge`, но понимание важно:

```cpp
#include <iostream>
#include <vector>

using namespace std;

vector<int> mergeSorted(const vector<int>& a, const vector<int>& b) {
    vector<int> res;
    res.reserve(a.size() + b.size());
    int i = 0, j = 0;
    while (i < (int)a.size() && j < (int)b.size()) {
        if (a[i] < b[j]) res.push_back(a[i++]);
        else             res.push_back(b[j++]);
    }
    while (i < (int)a.size()) res.push_back(a[i++]);
    while (j < (int)b.size()) res.push_back(b[j++]);
    return res;
}

int main() {
    vector<int> a = {1, 3, 5}, b = {2, 4, 6};
    for (int x : mergeSorted(a, b)) cout << x << " "; // 1 2 3 4 5 6
    cout << endl;
    return 0;
}
```

Это же слияние реализует `std::merge` в STL, а сам подход — основа сортировки слиянием (merge sort).

## 🔍 Вариации и где ещё применяется

| Задача                                              | Метод                                          |
| :-------------------------------------------------- | :--------------------------------------------- |
| Минимальная длина окна с условием                   | Классическое расширяющееся окно                |
| Число подмассивов с условием                        | $cnt += r - l + 1$                             |
| Слияние двух массивов / поиск пары с точной суммой  | Два индекса с разных сторон (после сортировки) |
| Сжатие (coordinate compression)                     | Два указателя по отсортированным копиям        |
| Максимум в каждом окне фиксированного размера       | Деки (не указатели!) — см. [[Дерево отрезков]] / [[Sqrt-декомпозиция и метод Мо]] |

> [!⚠️] Когда указатели не работают
> Если условие **не монотонно** (подмассив «хорош» в середине, но портится расширением в обе стороны) — два указателя бесполезны. Присматривайтесь: иногда работает `map`/`set` внутренних значений.

## 🔍 Нюансы

* **Форма цикла:** обычно `for (r...)` снаружи и `while (bad) l++` внутри. Главное — не забыть сдвинуть `l` при восстановлении условия.
* **Переполнение суммы:** `sum` и `cnt` могут сильно переполнять `int` → `long long`.
* **Граница ответа:** если ответ не найден, возвращайте явный признак (`-1` или «INF»), а не мусор.
* **Связь с [[Префиксные суммы и разности]]:** иногда задача «окно с суммой» решается и через префиксы + `lower_bound` — выбирайте то, что даёт меньшую асимптотику.
