# ДП по подмножествам (битмаски)

**ДП по подмножествам** — когда состояние описывает **целое подмножество** элементов битовой маской, при необходимости с дополнением «хвост» (последний элемент). Классика — задача коммивояжёра (TSP); отдельный мощный приём — ДП по профилю (замощения досок).

* **Число состояний:** $2^n$ масок, часто умноженное на $n$.
* **Когда использовать:** $n \le 20$–$22$. Для коммивояжёра с $O(2^n \cdot n^2)$ комфортный максимум ~ $n \le 15$–$16$.
* **Перебор всех подмасок каждой маски — суммарно $O(3^n)$:** ещё одна фирменная техника этого подхода.
* Основа: битовые операции — см. [[Битовые операции]].

---

## 🛠️ Идея: подмножество как маска

Битовая маска `mask` — целое число, где `bit k = 1` означает «элемент $k$ в подмножестве». Операции — быстрые битовые трюки:

* Проверка: `mask & (1 << k)`
* Добавление: `mask | (1 << k)`
* Удаление: `mask ^ (1 << k)` (если элемент был)
* Вся шкала от 0 до `(1 << n) - 1`.

Есть два типовых «фасона» таблицы:

1. `dp[mask]` — значение только по подмножеству: «можно ли разбить/набрать», максимальная выгода группы.
2. `dp[mask][v]` — значение по подмножеству + информация о последнем/первом элементе. Так устроена задача коммивояжёра.

---

## 💻 Задача коммивояжёра (TSP / «продавец»)

Продавец начинает в городе `0`, должен **ровно один раз** посетить все остальные города и вернуться в `0`, минимизировав сумму дорог.

Рекуррента: `dp[mask][u]` — минимальная стоимость маршрута, который прошёл ровно по всем городам из `mask` и закончился в `u`. Последний шаг — из какого-то `v` в `u`:

$$dp[mask][u] = \min_{v \in mask,\ v \ne u} dp[mask \setminus u][v] + dist[v][u]$$

База $dp[1][0] = 0$ (начали в городе 0). Ответ — вернуться из последнего города в 0.

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int main() {
    int n;
    cin >> n;
    vector<vector<int>> dist(n, vector<int>(n));
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            cin >> dist[i][j];

    const int INF = 1e9;
    int full = (1 << n) - 1;

    // dp[mask][u] — стоимость обхода ровно городов mask с концом в u
    vector<vector<int>> dp(1 << n, vector<int>(n, INF));
    dp[1][0] = 0; // старт в городе 0

    for (int mask = 1; mask <= full; mask++) {
        for (int v = 0; v < n; v++) {
            if (!(mask & (1 << v))) continue;
            for (int u = 0; u < n; u++) {
                if (!(mask & (1 << u))) continue;
                if (u == v) continue;
                // убираем u из mask: последний шаг v -> u
                dp[mask][u] = min(dp[mask][u], dp[mask & ~(1 << u)][v] + dist[v][u]);
            }
        }
    }

    int ans = INF;
    for (int v = 1; v < n; v++)
        ans = min(ans, dp[full][v] + dist[v][0]); // возврат в город 0
    cout << ans << endl;
    return 0;
}
```

* Переход берёт `mask & ~(1 << u)` — подмножество **меньше** текущего, значит уже посчитано (идём по маскам по возрастанию).
* Сложность $O(2^n \cdot n^2)$, память $O(2^n \cdot n)$.
* Восстановление маршрута — как в [[Динамическое программирование. Основы]]: массив `from[mask][u]` = город, из которого пришли.

## 🧮 Перебор подмасок за $O(3^n)$

Частая подзадача: для **каждой** маски перебрать **все** её подмаски. Код — знаменитый трюк `sub = (sub - 1) & mask`:

```cpp
for (int mask = 0; mask < (1 << n); mask++) {
    for (int sub = mask; sub; sub = (sub - 1) & mask) {
        // sub — непустая подмаска mask
    }
}
```

**Почему не $2^n \times 2^n$, а всего $3^n$?** Каждый элемент независимо находится в одном из трёх состояний относительно пары `(mask, sub)`:

1. не попал в `mask`;
2. попал в `mask`, но не в `sub`;
3. попал в обе.

Всех комбинаций $3^n$ — поэтому суммарное число итераций $O(3^n)$, осмысленное при $n \le 15$–$18$.

Типовое применение — ДП по разбиению: «разделить подмножество на части и объединить ответы»:

$$dp[mask] = \max_{sub \subset mask} dp[mask \setminus sub] + cost[sub]$$

Примеры задач: разбиение на группы с выигрышем группы, максимальное паросочетание, этаж/покраска подмножеств.

## 📌 ДП по профилю (замощения доски)

Другой фирменный приём — **профильный ДП**: состояние — битовая маска «границы» между заполненной и незаполненной частями доски. Классика — посчитать количество способов замостить доску $n \times m$ домино $2 \times 1$ (и $1 \times 2$) при небольшой меньшей стороне ($m \le 10$–$12$).

Профиль — маска занятости текущей строки: клетки, куда «торчат» вертикальные домино из предыдущей строки. Проход по клеткам строки либо ставит вертикальную домино (выставляя бит в следующем профиле), либо две горизонтальные.

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;
using int64 = long long;

int n, m;
int64 dp[1 << 12], nxt[1 << 12];

// Строим переход: из профиля mask во все достижимые профили nextMask
void go(int pos, int mask, int nextMask, int64 val) {
    if (pos == m) { nxt[nextMask] += val; return; }
    if (mask & (1 << pos)) {                       // клетка занята домино сверху
        go(pos + 1, mask, nextMask, val);
    } else {
        go(pos + 1, mask, nextMask | (1 << pos), val); // вертикальное домино вниз
        if (pos + 1 < m && !(mask & (1 << (pos + 1))))
            go(pos + 2, mask, nextMask, val);           // горизонтальное домино
    }
}

int main() {
    while (cin >> n >> m, (n || m)) {
        if (n < m) swap(n, m); // профиль держим по меньшей стороне

        fill(dp, dp + (1 << m), 0);
        dp[0] = 1;
        for (int row = 0; row < n; row++) {
            fill(nxt, nxt + (1 << m), 0);
            for (int mask = 0; mask < (1 << m); mask++)
                if (dp[mask]) go(0, mask, 0, dp[mask]);
            swap(dp, nxt);
        }
        cout << dp[0] << endl; // 0: ничего не торчит за последнюю строку
    }
    return 0;
}
```

Сложность: $O(n \times 2^m \times m)$ с переходом, «скользящим» по клетке — меньше множитель, если младшую сторону держать в профиле.

## 🔍 Нюансы

* **Пределы:** $2^{20} \approx 10^6$ масок, и с множителем $n$ — ещё $20\times$. ДП по битмаскам живёт при $n \le 20$–$22$, дальше — либо другой алгоритм, либо [[Встреча посередине (Meet-in-the-Middle)]] из [[Рекурсия и перебор]].
* **Инициализация:** маска с одним элементом — `1 << k`, а не `1`.
* **Переполнение:** число способов в задачах на замощения/подсчёт — `long long`.
* **Расширяемость:** если к «подмножеству» нужно привязать ещё информацию (последний город, предыдущая цифра), добавляйте размерность таблицы — стандартное состояние `dp[mask][tail]`.
* **Связь:** техника таблиц и восстановления — из [[Динамическое программирование. Основы]]; subset sum из [[Рюкзак]] тоже решается через `dp[mask]`; битовая арифметика — из [[Битовые операции]].
