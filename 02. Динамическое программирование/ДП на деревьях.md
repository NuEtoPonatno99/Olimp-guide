# ДП на деревьях

**ДП на деревьях** — класс задач, где дерево подвешивается за произвольную вершину, а подзадача — это **поддерево**. Поддеревья не пересекаются, поэтому рекуррента оказывается простой, а оба классических прохода стоят $O(n)$.

* **Проход 1 (DFS снизу вверх):** считаем ответы для всех поддеревьев, начиная с листьев.
* **Проход 2 (переподвешивание / rerooting):** переносим корень и пересчитываем ответы для «остальной части дерева» сверху вниз.
* **Сложность:** $O(n)$ времени, $O(n)$ памяти.

---

## 🛠️ Идея: подвешенное дерево и рекуррента через детей

Подвесьте дерево за вершину `0` (любую). У каждой вершины появляются **дети** — компоненты связности после удаления родителя. Любая величина про поддерево `v` выражается через детей:

* **Размер поддерева:** $sz[v] = 1 + \sum\limits_{u \in son(v)} sz[u]$
* **Сумма расстояний от `v` до вершин её поддерева:** $sum[v] = \sum\limits_{u} (sum[u] + sz[u])$ — дорога до каждой вершины ребёнка удлиняется на ребро `v–u`.

База — лист: у него детей нет, $sz = 1$, $sum = 0$. Это ровно схема [[Динамическое программирование. Основы]]: таблица = массив по вершинам, порядок обхода = от листьев к корню.

## 💻 Классика: сумма расстояний до всех вершин

Задача: для **каждой** вершины посчитать сумму расстояний от неё до всех остальных вершин дерева. Наивно — $O(n^2)$ запусков обходов; ДП с переподвешиванием делает всё за два обхода.

```cpp
#include <iostream>
#include <vector>
#include <functional>

using namespace std;
using int64 = long long;

int n;
vector<vector<int>> g;
vector<int64> sz, sum, ans;

// Проход 1: размеры поддеревьев и сумма расстояний внутри поддерева (до корня 0)
void dfs1(int v, int p) {
    sz[v] = 1;
    sum[v] = 0;
    for (int u : g[v]) {
        if (u == p) continue;
        dfs1(u, v);
        sz[v] += sz[u];
        sum[v] += sum[u] + sz[u]; // дорога v-u проходится по разу на каждую вершину поддерева u
    }
}

// Проход 2: переподвешивание. ans[u] выражаем через ans[v] родителя.
void dfs2(int v, int p) {
    for (int u : g[v]) {
        if (u == p) continue;
        // переносим корень v -> u: sz[u] вершин стали на 1 ближе, (n - sz[u]) — на 1 дальше
        ans[u] = ans[v] - sz[u] + (n - sz[u]);
        dfs2(u, v);
    }
}

int main() {
    cin >> n;
    g.assign(n, {});
    for (int i = 0; i < n - 1; i++) {
        int a, b;
        cin >> a >> b;
        a--; b--;
        g[a].push_back(b);
        g[b].push_back(a);
    }

    sz.assign(n, 0);
    sum.assign(n, 0);
    dfs1(0, -1);   // посчитали для корня-0
    ans = sum;     // для корня ответ уже известен
    dfs2(0, -1);   // пересчитали для всех детей и их детей

    for (int64 x : ans) cout << x << " ";
    cout << endl;
    return 0;
}
```

**Главная формула переподвешивания** — перенос корня с `v` на ребёнка `u`:

$$ans[u] = ans[v] - sz[u] + (n - sz[u])$$

Разбор: поддерево `u` (в нём $sz[u]$ вершин) при новом корне становится на одну единицу **ближе**, а все остальные $n - sz[u]$ вершин — на одну **дальше**. Так ответ для каждой вершины считается за $O(1)$ от родителя.

## 💻 Бонус: диаметр дерева через ДП

Диаметр — самая длинная цепочка вершин. В поддереве `v` диаметр либо целиком внутри одного поддерева ребёнка, либо проходит через `v` и собирается из двух самых длинных веток вниз.

```cpp
int diameter = 0;

// Возвращает высоту поддерева v (самый длинный путь вниз).
int dfs(int v, int p) {
    int h1 = 0, h2 = 0; // две самые длинные ветки вниз из v
    for (int u : g[v]) {
        if (u == p) continue;
        int h = dfs(u, v) + 1;
        if (h > h1) { h2 = h1; h1 = h; }
        else if (h > h2) h2 = h;
    }
    if (h1 + h2 > diameter) diameter = h1 + h2; // путь с вершиной v на «перевале»
    return h1;
}
```

После `dfs(0, -1)` в `diameter` лежит искомое значение. Никакого переподвешивания: один проход снизу вверх.

## 🔍 Нюансы

* **Глубина рекурсии:** на дереве-«цепочке» из $10^5$ вершин рекурсивный `dfs` переполнит стандартный стек. На Codeforces поднимают лимит рекурсии или пишут итеративный обход со стеком — проверяйте по ограничениям.
* **Оба прохода — $O(n)$:** дерево обходится быстрее общего графа, поэтому ДП на деревьях «бесплатно».
* **Когда переподвешивание заходит:** нужна формула, которая быстро пересчитывает ответ ребёнка из ответа родителя (как $ans[u] = ans[v] - sz[u] + (n - sz[u])$). Это переиспользование идеи один раз посчитанного — тот же принцип, что в [[Динамическое программирование. Основы]].
* **Связь:** дерево — частный случай [[Графы]]; список смежности из [[Список смежности(пример)]] — удобное представление для обходов.
