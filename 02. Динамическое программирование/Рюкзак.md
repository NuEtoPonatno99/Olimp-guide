# Рюкзак

**Задача о рюкзаке** — есть $N$ предметов с весами $w_i$ и ценностями $c_i$ и рюкзак вместимостью $W$. Нужно выбрать набор предметов так, чтобы суммарная ценность была максимальной, не превысив вместимость.

* **Три версии:** 0/1 (каждый предмет можно взять максимум один раз), неограниченный (копий сколько угодно), ограниченный (у предмета есть конечное число копий $cnt_i$).
* **Общая идея:** таблица ДП по вместимости. Сложность $O(N \times W)$.
* **Важнейшая деталь — направление обхода по вместимости:** именно оно отличает версии друг от друга.

---

## 🛠️ Рюкзак 0/1

Каждый предмет берём либо целиком, либо никак. Таблица — одна строка: `dp[s]` = максимальная ценность, которую можно уложить в рюкзак вместимости $s$.

Рекуррента на каждом предмете $i$:

$$dp[s] = \max(dp[s],\ dp[s - w_i] + c_i)$$

Цикл по $s$ идёт **сверху вниз** (от $W$ к $w_i$): тогда `dp[s - w_i]` ещё не «испорчен» текущим предметом, и тот не может быть взят дважды.

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int main() {
    int n, W;
    cin >> n >> W;

    vector<int> w(n), c(n);
    for (int i = 0; i < n; i++) cin >> w[i] >> c[i];

    vector<int> dp(W + 1, 0);
    for (int i = 0; i < n; i++) {
        for (int s = W; s >= w[i]; s--) {          // обход ВНИЗ — предмет один раз!
            dp[s] = max(dp[s], dp[s - w[i]] + c[i]);
        }
    }

    cout << dp[W] << endl;
    return 0;
}
```

**Восстановление набора предметов:** однострочной таблицы мало — держим двумерную `dp[i][s]` (по номеру предмета и вместимости) и идём назад:

```cpp
// Печатает номера взятых предметов (1-индексация), идя от (n, W)
int rem = W;
for (int i = n - 1; i >= 0; i--) {
    if (dp[i + 1][rem] != dp[i][rem]) { // предмет i взят
        cout << i + 1 << " ";
        rem -= w[i];
    }
}
```

## 💻 Неограниченный рюкзак

Идея та же, но обход **снизу вверх** (от $w_i$ к $W$): `dp[s - w_i]` успевает обновиться текущим предметом → предмет берётся много раз (это и есть «неограниченность»).

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int main() {
    int n, W;
    cin >> n >> W;

    vector<int> w(n), c(n);
    for (int i = 0; i < n; i++) cin >> w[i] >> c[i];

    vector<int> dp(W + 1, 0);
    for (int i = 0; i < n; i++) {
        for (int s = w[i]; s <= W; s++) {          // обход ВВЕРХ — предмет можно много раз
            dp[s] = max(dp[s], dp[s - w[i]] + c[i]);
        }
    }

    cout << dp[W] << endl;
    return 0;
}
```

Единственное отличие от 0/1 — направление внутреннего цикла. Вот и вся разница.

## 💻 Ограниченный рюкзак и оптимизация «разделяй» по количеству

У каждого предмета $cnt_i$ копий. **Наивно:** распаковать каждую копию в отдельный предмет 0/1 — станет $K = \sum cnt_i$ предметов и сложность $O(W \times K)$. Если $cnt$ большие — слишком медленно.

**Оптимизация «разделяй по количеству» (бинарное разложение):** разбиваем $cnt$ копий предмета на группы размером $1, 2, 4, 8, \dots, 2^k$ и остаток. Каждая группа становится одним предметом с весом `размер × w` и ценностью `размер × c`. Любое количество копий от 1 до $cnt$ выражается суммой таких групп (двоичная система исчисления), а групп всего $O(\log cnt)$.

Пример: $cnt = 10$ → группы $\{1, 2, 4, 3\}$. Количество 7 = 1 + 2 + 4, количество 9 = 2 + 4 + 3 и т.д.

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int main() {
    int n, W;
    cin >> n >> W;

    vector<int> vw, vc;            // «развёрнутые» группы предметов
    for (int i = 0; i < n; i++) {
        int w, c, cnt;
        cin >> w >> c >> cnt;
        for (int k = 1; cnt > 0; k *= 2) {
            int take = min(k, cnt); // размер группы: 1, 2, 4, ..., остаток
            vw.push_back(take * w);
            vc.push_back(take * c);
            cnt -= take;
        }
    }

    // Дальше — обычный 0/1 рюкзак по получившимся группам
    vector<int> dp(W + 1, 0);
    for (int i = 0; i < (int)vw.size(); i++) {
        for (int s = W; s >= vw[i]; s--) {
            dp[s] = max(dp[s], dp[s - vw[i]] + vc[i]);
        }
    }

    cout << dp[W] << endl;
    return 0;
}
```

С благодарностью за двоичную систему предметов после распаковки — $O(\sum \log cnt_i)$, а не $O(\sum cnt_i)$.

## 🧮 Сводная таблица версий

| Версия                                | Переход                                          | Направление обхода  | Асимптотика                     |
| :------------------------------------ | :----------------------------------------------- | :------------------ | :------------------------------ |
| **0/1**                               | `dp[s] = max(dp[s], dp[s-w]+c)`                  | ВНИЗ `W → w`        | $O(N \times W)$                 |
| **Неограниченный**                    | та же рекуррента                                 | ВВЕРХ `w → W`       | $O(N \times W)$                 |
| **Ограниченный (наивно)**             | распаковать в 0/1                                | ВНИЗ                | $O(W \times \sum cnt_i)$        |
| **Ограниченный («разделяй»)**: группы | 1, 2, 4, …, остаток → 0/1                        | ВНИЗ                | $O(W \times \sum \log cnt_i)$   |

## 🔍 Нюансы

* **Большая вместимость:** если $W \sim 10^9$, рюкзак по весам уже не подходит ($W$ в таблицу не влезает). Тогда думают «наоборот»: считают $dp[c]$ = минимальный вес для ценности $c$ и ищут минимум над стоимостью.
* **Переполнение:** ценности суммируются — `long long`.
* **Частный случай — subset sum:** «можно ли набрать сумму $S$» решается рюкзаком 0/1 с $c_i = w_i$.
* **База:** всё это — частный случай [[Динамическое программирование. Основы]]. Направления обхода легко запомнить: **вниз = предмет один раз, вверх = предмет повторный**.
