# Бор (Trie)

**Бор (Trie, префиксное дерево)** — дерево, в котором каждое ребро помечено символом, а путь от корня до терминальной вершины задаёт слово из словаря. Вставка, поиск и проверка «есть ли строка с префиксом $P$» работают за $O(|s|)$ — независимо от размера словаря.

* **Сложность операций:** $O(|s|)$ на вставку/поиск/удаление.
* **Память:** $O(\text{сумма длин всех строк} \times |\Sigma|)$ для массива `next` (вариант на `map` — меньше памяти, но $O(\log |\Sigma|)$ переход).
* **C++ STL:** готового бора нет — пишем массивом вершин.
* **База для:** автодополнения, сортировки строк, XOR-max, автомата Ахо–Корасик.

---

## 🛠️ Идея

Корень — пустая строка. У каждого узла: переходы на символы (`next`) и флаг `terminal` «здесь кончается слово». Число вершин не превышает суммарной длины всех строк $+ 1$.

Компактная реализация — **массив переходов** и динамический `vector` вершин:

```cpp
#include <cstring>
#include <string>
#include <vector>

using namespace std;

const int ALPH = 26;

struct TrieNode {
    int next[ALPH];
    bool terminal = false;
    TrieNode() { memset(next, -1, sizeof(next)); }
};

vector<TrieNode> trie(1);       // вершина 0 — корень (пустая строка)

void add(const string& s) {
    int v = 0;
    for (char ch : s) {
        int c = ch - 'a';
        if (trie[v].next[c] == -1) {
            trie[v].next[c] = (int)trie.size();
            trie.emplace_back();
        }
        v = trie[v].next[c];
    }
    trie[v].terminal = true;
}
```

* Вершины — просто индексы в `vector<TrieNode>`; бор «растёт» на `emplace_back`, без выделений на хипе по одному узлу.
* `terminal` отличает слово от его **собственного** префикса: `"cat"` и `"cats"` спокойно сосуществуют.

## 💻 Операции

```cpp
bool exists(const string& s) {        // есть ли ровно слово s
    int v = 0;
    for (char ch : s) {
        int c = ch - 'a';
        if (trie[v].next[c] == -1) return false;
        v = trie[v].next[c];
    }
    return trie[v].terminal;
}

// Чтобы отвечать «сколько слов начинается на префикс», в add()
// ведите cnt[v]++ на каждой пройденной вершине, тогда
// cnt[вершина-конец-префикса] = количество слов с этим префиксом.

void dfsPrint(int v, string cur) {    // лексикографический вывод всех слов
    if (trie[v].terminal) cout << cur << '\n';
    for (int c = 0; c < ALPH; c++)    // рёбра обходим в алфавитном порядке
        if (trie[v].next[c] != -1)
            dfsPrint(trie[v].next[c], cur + char('a' + c));
}
```

* **Поиск по префиксу:** спустились → обошли поддерево → все `terminal` — это «автодополнение».
* **Сортировка слов** бора эквивалентна лексикографической — DFS с алфавитным порядком рёбер.
* **XOR-max:** строку-число заводим по битам в бор с алфавитом $\{0, 1\}$ — пара с максимальным XOR подбирается за $O(32)$ на число (см. [[Битовые операции]]).

## 🧮 Где применяется

| Задача                                        | Решение через бор                                    |
| :-------------------------------------------- | :--------------------------------------------------- |
| Словарь: вставка/поиск/наличие слова          | `add` / `exists`, $O(|s|)$                          |
| Сколько слов с префиксом $P$                  | `cnt` в вершине конца $P$                            |
| Автодополнение / все слова с префиксом        | DFS поддерева                                        |
| Сортировка строк                               | DFS в алфавитном порядке                             |
| Максимальный XOR пары чисел                   | бор по битам, $O(32 \cdot n)$ при $n$ чисел          |
| «Есть ли слово — префикс другого»             | проход по бору (телефонные номера, коды)             |
| Множество паттернов в тексте                  | автомат Ахо–Корасик (бор + откаты из [[Префикс-функция и КМП]]) |

> [!⚠️] Память массива next
> Узел `next[26]` + `terminal` — ~104 байта на вершину (`int[26]` + `bool` + выравнивание). Миллион вершин ≈ 100 MB — впритык. Альтернатива: `map<char,int>` (меньше памяти, `O(log|Σ|)` на переход) или сжатое представление. Для задач на латиницу обычно хватает массива.

## 🔍 Нюансы

* **Алфавит в `ALPH`:** латиница, цифры, биты — меняйте `ALPH` и функцию индексации `ch - 'a'` (для битов — `ch - '0'`).
* **Пустая строка:** флаг `terminal` в корне делает пустую строку элементом словаря — важно в задачах про подстроки.
* **Удаление:** векторная версия «в одну сторону» — физическое удаление редкое; можно лишь сбрасывать `terminal` и `cnt`, память не возвращается.
* **Сложность O(|s|), а не O(1):** бор в среднем быстрее `unordered_set<string>` не за счёт асимптотики, а за счёт отсутствия хэшей и коллизий.
* **Порядок рёбер при выводе слов** обязан быть алфавитным — иначе сортировка бором не работает.
