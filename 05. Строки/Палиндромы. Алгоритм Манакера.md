# Палиндромы. Алгоритм Манакера

**Алгоритм Манакера** находит **все** палиндромные подстроки строки за $O(n)$: два массива радиусов — `d1[i]` (нечётные палиндромы с центром в позиции $i$) и `d2[i]` (чётные, центр между $i-1$ и $i$). Асимптотика оптимальна: всего различных центров $O(n)$, и каждый обрабатывается один раз.

* **Сложность:** $O(n)$ по времени и памяти — линейный и оптимальный.
* **Радиус $d1[i] = k$:** внутри идут палиндромы нечётных длин $1, 3, \dots, 2k-1$ с центром $i$.
* **Радиус $d2[i] = k$:** чётные палиндромы длин $2, 4, \dots, 2k$ с центром между $i-1$ и $i$.
* **Выход:** число палиндромов, самый длинный, покрытие каждой позиции — всё из двух массивов за $O(1)$ на запрос.

---

## 🛠️ Идея

Как и [[Z-функция]], Манакер держит окно — самый правый найденный палиндром `[l, r]` с центром. Внутри окна радиусы **зеркальны**: для позиции $i$ зеркало относительно центра окна — это `l + r - i`; берём `min(маленький радиус зеркала, до границы окна)` и дальше честно расширяем, пока символы совпадают.

```cpp
vector<int> manacherOdd(const string& s) {
    int n = (int)s.size();
    vector<int> d1(n);
    int l = 0, r = -1;
    for (int i = 0; i < n; i++) {
        int k = (i > r) ? 1 : min(d1[l + r - i], r - i + 1);  // зеркало
        while (i - k >= 0 && i + k < n && s[i - k] == s[i + k])
            k++;
        d1[i] = k--;                       // d1[i] считаем «радиус + 1»
        if (i + k > r) { l = i - k; r = i + k; }  // окно сдвинулось вправо
    }
    return d1;
}
```

Для чётных центр — «щель» между соседними символами, поэтому индексы сдвинуты на единицу:

```cpp
vector<int> manacherEven(const string& s) {
    int n = (int)s.size();
    vector<int> d2(n);
    int l = 0, r = -1;
    for (int i = 0; i < n; i++) {
        int k = (i > r) ? 0 : min(d2[l + r - i + 1], r - i + 1);
        while (i - k - 1 >= 0 && i + k < n && s[i - k - 1] == s[i + k])
            k++;
        d2[i] = k--;
        if (i + k > r) { l = i - k - 1; r = i + k; }
    }
    return d2;
}
```

* `d2[i] = k` означает: центр после символа $i-1$, палиндромы длины $2, 4, \dots, 2k$.
* Легче ошибиться в чётном варианте — проверяйте оба массива на `"aa"` (там должен родиться радиус $d2[1] = 1$).

## 💻 Что из массивов достаётся

| Вопрос                                        | Ответ через радиусы                          |
| :-------------------------------------------- | :------------------------------------------- |
| Число всех палиндромных подстрок              | $\sum_i (d1[i] + d2[i])$                     |
| Самый длинный палиндром                       | `max(2*d1[i]-1, 2*d2[i])`                    |
| Палиндром ли подстрока $[l, r]$               | сравнить с центром $(l+r)/2$ и радиусом      |
| Число палиндромов с концом в каждой позиции   | дифмассив прибавок из радиусов               |
| Longest palindromic substring после правки    | радиус до первого несовпадения (в обе стороны) |

```cpp
#include <iostream>
#include <string>
#include <vector>

using namespace std;

// ... manacherOdd и manacherEven (см. выше) ...

int main() {
    string s;
    cin >> s;
    vector<int> d1 = manacherOdd(s);
    vector<int> d2 = manacherEven(s);

    long long total = 0;          // число всех палиндромов может быть ~10^10
    int best = 0;                 // длина самого длинного
    for (int i = 0; i < (int)s.size(); i++) {
        total += d1[i] + d2[i];
        best = max(best, 2 * d1[i] - 1);
        best = max(best, 2 * d2[i]);
    }
    cout << "palindromes: " << total << '\n';
    cout << "longest: " << best << '\n';
    return 0;
}
```

> [!⚠️] Палиндромы вложены
> Каждый радиус — это сразу **несколько** палиндромов (центр даёт $d1[i]$ вложенных нечётных). Поэтому сумма радиусов может превзойти длину строки многократно — брать `int` для `total` нельзя.

## 🧮 Взаимозаменяемость с хэшами

Манакера на олимпиадах часто заменяют [[Хеширование строк]]: бинпоиск по длине палиндрома с центром в $i$ даёт $O(n \log n)$ и вероятностные ответы. Манакер выигрывает строгостью ($O(n)$, без коллизий), хэш — универсальностью (тот же предподсчёт годится для кучи других задач).

| Подход                  | Время        | Коллизии | Сложность запоминания |
| :---------------------- | :----------- | :------- | :-------------------- |
| Манакер                 | $O(n)$       | нет      | окно + 2 массива      |
| Хэш + бинпоиск по центру | $O(n \log n)$ | да      | проще (уже есть хэш)  |

## 🔍 Нюансы

* **Не забыть второй массив:** без `d2` строка `"aa"` не выдаст палиндром длины 2 — ответы рассинхронизируются.
* **Индексы чётных ловят на единице:** `s[i - k - 1]` в `while` — распространённый источник off-by-one. Тестируйте на `"aa"`, `"aba"`, `"abba"`.
* **`long long` для суммы:** $n = 10^5$ даёт до $\sim 1.25 \cdot 10^{10}$ палиндромов (строка из одинаковых букв) — переполнение `int`.
* **Сравнение с [[Префикс-функция и КМП]]:** КМП ищет вхождения, Манакер — палиндромы; оба строго линейны.
