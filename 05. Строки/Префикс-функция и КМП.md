# Префикс-функция и КМП

**Префикс-функция** $\pi[i]$ — длина наибольшего *собственного* префикса строки $s[0..i]$, который одновременно является её суффиксом. На ней строится **алгоритм Кнута–Морриса–Пратта (КМП)** — поиск всех вхождений подстроки за $O(n + m)$ без хэшей и вероятностей.

* **Сложность построения $\pi$:** $O(n)$ по времени, $O(n)$ памяти.
* **Сложность КМП:** $O(n + m)$ на поиск (длина текста + длина паттерна).
* **Детерминизм:** в отличие от [[Хеширование строк]], результат гарантированно точный.
* **Бонус:** из $\pi$ достаётся период строки, сжатие, количество вхождений.

---

## 🛠️ Идея

Для позиции $i$ опираемся на уже посчитанное значение $j = \pi[i-1]$ и пытаемся расширить совпадение. Пока символ `s[i]` не совпадает с `s[j]`, откатываемся по «прыжкам бордов»: $j = \pi[j-1]$.

$$s[0..j-1] = s[i-j+1..i]$$

```cpp
vector<int> prefixFunction(const string& s) {
    int n = (int)s.size();
    vector<int> pi(n, 0);
    for (int i = 1; i < n; i++) {
        int j = pi[i - 1];
        while (j > 0 && s[i] != s[j])     // не совпало — откат по бордам
            j = pi[j - 1];
        if (s[i] == s[j]) j++;            // совпало — увеличиваем борд
        pi[i] = j;
    }
    return pi;
}
```

* **Линейность:** каждое успешное `j++` — один раз на позицию, а все откаты суммарно стоят $O(n)$, потому что `j` только растёт между откатами.
* **Смысл `π[n-1] = k`:** наибольший *собственный* борд (и префикс, и суффикс) имеет длину $k$. Из него — **период**: если $n$ делится на $n-k$, то период строки равен $n-k$.

## 💻 КМП: поиск вхождений

Хитрость: склеиваем `pattern + '#' + text` (разделитель не встречается в строках) и считаем одну префикс-функцию. Каждая позиция в тексте, где $\pi[i] = |pattern|$, — это вхождение.

```cpp
#include <iostream>
#include <string>
#include <vector>

using namespace std;

vector<int> prefixFunction(const string& s) {
    int n = (int)s.size();
    vector<int> pi(n, 0);
    for (int i = 1; i < n; i++) {
        int j = pi[i - 1];
        while (j > 0 && s[i] != s[j]) j = pi[j - 1];
        if (s[i] == s[j]) j++;
        pi[i] = j;
    }
    return pi;
}

int main() {
    string text, pattern;
    cin >> text >> pattern;
    int p = (int)pattern.size();

    string s = pattern + "#" + text;      // '#' не встречается ни в pattern, ни в text
    vector<int> pi = prefixFunction(s);

    bool found = false;
    for (int i = 0; i < (int)s.size(); i++) {
        if (pi[i] == p) {                 // борд длины p = полное совпадение
            cout << i - 2 * p << " ";     // «отматываем» pattern + '#'
            found = true;
        }
    }
    if (!found) cout << "no matches";
    cout << '\n';
    return 0;
}
```

* **Разделитель обязателен:** без `'#'` борд мог бы «переехать» через границу и дать ложное вхождение на стыке.
* Позиции выводятся по возрастанию; сдвиг `i - 2 * p` = (индекс в склейке) − (длина pattern + 1 для `'#'`).

> [!⚠️] Период через `π`
> Наименьший период строки равен $n - \pi[n-1]$, но только если $n \% (n - \pi[n-1]) == 0$. Иначе строка непериодическая и «период» равен $n$ — не путайте наибольший борд с минимальным периодом вне делимости.

## 🧮 Продвинутые применения π

* **Минимальный период,** сжатие строки повторением куска.
* **Подсчёт вхождений паттерна с перекрытиями:** π на `pattern + '#' + text` — каждая позиция с $\pi[i] = p$.
* **КМП-автомат:** мемоизация откатов `go[i][c]` позволяет «кормить» текст по одному символу за $O(1)$ — удобно при нескольких паттернах.
* **Сравнение строк за $O(1)$ после предподсчёта** — но это уже [[Хеширование строк]].

## 🔍 Нюансы

* **`j = pi[j-1]` двигает влево не на 1:** борды вкладываются друг в друга ($\pi[\pi[i]-1]$, ...), и это свойство даёт линейность. Не пробуйте `j--` — потеряете $O(n)$.
* **~ vs [[Z-функция]]:** π строится «от конца», z — «от начала»; для поиска вхождений годятся обе, для периода чаще берут π.
* **Склейка с разделителем:** символ из алфавита в качестве `'#'` сломает поиск, если встретится в строках — берите нестандартный символ или `char(0)`.
* **Детерминизм vs хэш:** КМП без коллизий за ту же асимптотику — почти всегда предпочтительнее хэшей при поиске вхождений.
