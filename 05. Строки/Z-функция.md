# Z-функция

**Z-функция** $z[i]$ — длина наибольшего общего префикса строки $s$ и её суффикса $s[i..]$. Двоюродный брат [[Префикс-функция и КМП]]: тоже $O(n)$ и тоже ищет вхождения подстроки, но работает «от начала строки», а не «от конца», и часто проще запоминается.

* **Сложность построения:** $O(n)$ по времени и памяти.
* **Определение:** $z[i]$ = «насколько $s[i..]$ совпадает с началом $s$»; $z[0]$ обычно полагают $= 0$.
* **Использование:** поиск вхождений за $O(n + m)$, проверка периода, подсчёт вхождений префиксов.

---

## 🛠️ Идея

Ключевая фишка — **окно** `[l, r]`: самый правый уже просмотренный отрезок, целиком совпадающий с началом строки. Символы внутри окна не сравниваются заново: значение `z[i]` «заимствуется» у зеркальной позиции `z[i - l]` и обрезается до правой границы.

$$z[i] = \max_k \{ k : s[0..k-1] = s[i..i+k-1] \}$$

```cpp
vector<int> zFunction(const string& s) {
    int n = (int)s.size();
    vector<int> z(n, 0);
    int l = 0, r = 0;                 // окно [l, r]: s[l..r] = s[0..r-l]
    for (int i = 1; i < n; i++) {
        if (i <= r)
            z[i] = min(r - i + 1, z[i - l]);   // заимствование из окна
        while (i + z[i] < n && s[z[i]] == s[i + z[i]])  // честное дорасширение
            z[i]++;
        if (i + z[i] - 1 > r) {       // окно уехало вправо — обновляем
            l = i;
            r = i + z[i] - 1;
        }
    }
    return z;
}
```

* Строка из одинаковых букв (`"aaaaa"`) — худший случай для наивной версии, но с окном каждый символ просматривается $O(1)$ раз.
* `min(...)` обязателен: заимствованное значение не может выходить за границу окна.

## 💻 Поиск вхождений через Z

Та же склейка, что в КМП: `pattern + '#' + text`. Каждое `z[i] == |pattern|` — вхождение.

```cpp
#include <iostream>
#include <string>
#include <vector>

using namespace std;

vector<int> zFunction(const string& s) {
    int n = (int)s.size();
    vector<int> z(n, 0);
    int l = 0, r = 0;
    for (int i = 1; i < n; i++) {
        if (i <= r) z[i] = min(r - i + 1, z[i - l]);
        while (i + z[i] < n && s[z[i]] == s[i + z[i]]) z[i]++;
        if (i + z[i] - 1 > r) { l = i; r = i + z[i] - 1; }
    }
    return z;
}

int main() {
    string text, pattern;
    cin >> text >> pattern;
    int p = (int)pattern.size();

    string s = pattern + "#" + text;
    vector<int> z = zFunction(s);

    bool found = false;
    for (int i = p + 1; i < (int)s.size(); i++) {  // начинаем после "pattern#"
        if (z[i] == p) {
            cout << i - (p + 1) << " ";            // позиция в text
            found = true;
        }
    }
    if (!found) cout << "no matches";
    cout << '\n';
    return 0;
}
```

Период через z чуть менее прямолинейный, чем через π: строка периодична с периодом $k$, если $z[k] \ge n - k$ (остаток хвоста накрыт совпадением с началом).

---

## 🧮 Когда брать π, когда z

| Задача                                    | π                                 | z                                        |
| :---------------------------------------- | :-------------------------------- | :--------------------------------------- |
| Все вхождения подстроки                   | да, `π[pattern+'#'+text]`         | да, `z[pattern+'#'+text]`                |
| Минимальный период / борд                 | удобно: $n - \pi[n-1]$            | через $z[k] \ge n-k$                     |
| «Сколько раз префикс входит в строку»     | через доп. пересчёт                | напрашивается само: `z[i]` сразу даёт    |
| Простота запоминания                      | откаты $j=\pi[j-1]$ иногда путают | окно + заимствование читается легче      |

* Обе функции детерминированы и линейны; выбор — вкусовой.
* Для сравнения с [[Хеширование строк]]: z даёт точный ответ без вероятностей, но требует склейки и $O(n + m)$ времени.

## 🔍 Нюансы

* **Окно — обязательная часть, а не оптимизация:** без `[l, r]` алгоритм деградирует до $O(n^2)$ на «правильных» строках.
* **Выход за границы:** в `while` обязательно условие `i + z[i] < n` — классическая ошибка вылета за массив.
* **Разделитель:** без `'#'` в склейке (или если он совпадает с алфавитом) z «перетечёт» через границу pattern|text.
* **`z[0]`:** неопределен по определению, в реализации — `0`. Не используйте его в вычислениях.
