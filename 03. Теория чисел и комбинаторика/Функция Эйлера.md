# Функция Эйлера

**Функция Эйлера** $\varphi(n)$ — количество чисел от $1$ до $n$, взаимно простых с $n$ (то есть $\gcd(k, n) = 1$). Краеугольный камень модулярной арифметики и конкурсной теории чисел.

* **Формула через факторизацию:** $\varphi(n) = n \prod_{p \mid n} \left(1 - \frac{1}{p}\right)$, произведение по простым делителям.
* **Свойство произведения:** $\varphi(a \cdot b) = \varphi(a) \cdot \varphi(b)$ при $\gcd(a, b) = 1$.
* **Предподсчёт всех $\varphi(1..n)$:** линейное решето в стиле спф, $O(n)$ суммарно.
* **Связь с [[Модулярная арифметика]]:** теорема Эйлера $a^{\varphi(m)} \equiv 1 \pmod m$ при $\gcd(a, m) = 1$ — обобщение малой теоремы Ферма.

---

## 🛠️ Идея: формула для одного числа

Простые множители — «выключенные» позиции: если $n = p_1^{e_1} \cdots p_r^{e_r}$, то

$$\varphi(n) = n \cdot \frac{p_1 - 1}{p_1} \cdot \frac{p_2 - 1}{p_2} \cdots \frac{p_r - 1}{p_r}$$

```cpp
#include <iostream>

using namespace std;

using ll = long long;

ll phi(ll n) {
    ll res = n;
    for (ll p = 2; p * p <= n; p++) {
        if (n % p == 0) {
            while (n % p == 0) n /= p;   // выбросить степень, оставить один множитель
            res -= res / p;              // res *= (1 - 1/p) в целых числах
        }
    }
    if (n > 1) res -= res / n;           // остался последний простой делитель > sqrt
    return res;
}

int main() {
    cout << phi(10) << endl; // 4: {1,3,7,9}
    cout << phi(1) << endl;  // 1 (по определению)
    return 0;
}
```

* `res -= res / p` — это ровно `res *= (p - 1) / p`, но в целых без плавающей точки.
* Цикл идёт до $\sqrt n$ — как в проверке простоты: после него `n` либо $1$, либо простое число.

## 💻 Решето для всех $\varphi(1..n)$

Считаем все значения сразу, как в [[Простые числа и решето Эратосфена]]: сначала $\varphi[i] = i$, затем для каждого простого $p$ «домножаем» все кратные на $(p-1)/p$.

```cpp
const int N = 1'000'000;

vector<int> phiAll(int n) {
    vector<int> phi(n + 1);
    iota(phi.begin(), phi.end(), 0); // phi[i] = i
    for (int i = 2; i <= n; i++) {
        if (phi[i] == i) {           // i — простое (ни один меньший делитель его не «тоже»)
            for (int j = i; j <= n; j += i)
                phi[j] -= phi[j] / i;  // phi[j] *= (i-1)/i
        }
    }
    return phi;
}
```

* Каждое простое обрабатывает только свои кратные — суммарно $O(n \log \log n)$, как у обычного решета.
* Проверка `phi[i] == i` ловит простые: составное к этому моменту уже уменьшено каким-то простым делителем.

> [!⚠️] $\varphi(1)$ и «мультипликативность»
> $\varphi(1) = 1$. Мультипликативность $\varphi(ab) = \varphi(a)\varphi(b)$ верна **только для взаимно простых** $a$ и $b$. Для $\varphi(2 \cdot 2) \ne \varphi(2)^2$ — это частая ловушка в ручных вычислениях.

## 💻 Применение: обратный элемент и большая степень

Теорема Эйлера: при $\gcd(a, m) = 1$ выполнено $a^{\varphi(m)} \equiv 1 \pmod m$. Два следствия:

* **Обратный элемент:** $a^{-1} = a^{\varphi(m) - 1} \bmod m$ — работает и для составного $m$ (обобщение Ферма из [[Модулярная арифметика]]).
* **Сокращение показателя:** $a^b \equiv a^{b \bmod \varphi(m)} \pmod m$ для взаимно простых — С++ переполнение в показателе уходит.

```cpp
#include <iostream>

using namespace std;

using ll = long long;

ll phi(ll n) { /* см. выше */ }

ll binpow(ll a, ll e, ll mod) {
    a %= mod;
    ll r = 1;
    while (e) {
        if (e & 1) r = r * a % mod;
        a = a * a % mod;
        e >>= 1;
    }
    return r;
}

// a^b mod m через сокращение показателя по теореме Эйлера
ll powModUsingPhi(ll a, ll b, ll m) {
    if (gcd(a, m) == 1) b %= phi(m); // нужно std::gcd
    return binpow(a, b, m);
}
```

## 🔍 Где применяется

| Задача                                        | Решение через                                          |
| :-------------------------------------------- | :----------------------------------------------------- |
| Считать взаимно простые с $n$ до $n$           | $\varphi(n)$ по формуле                                |
| Обратный элемент по составному модулю          | $a^{\varphi(m)-1}$ или [[Расширенный алгоритм Евклида]] |
| Степень с огромным показателем по модулю       | Сокращение $b \bmod \varphi(m)$                        |
| Период повторения последовательностей по модулю | Порядки элементов, делители $\varphi(m)$               |
| Сумма $\sum_{d | n} \varphi(d) = n$            | Тождество, полезное в свёртках сумматоров              |

## 🔍 Нюансы

* **Решето $\varphi$ по модулям:** для каждого $i$ после цикла по делителям — итог уже готов; никакого второго прохода.
* **Сокращение показателя:** формула $a^b \equiv a^{b \bmod \varphi(m)}$ верна только для $\gcd(a, m) = 1$; для общего случая нужно больше шагов (сравнения по степеням двойки).
* **Простые числа:** $\varphi(p) = p - 1$, и вся [[Модулярная арифметика]] с Ферма — частный случай Эйлера при простом модуле.
* **Переполнение факторизации:** в формуле $n \cdot \prod (1 - 1/p)$ накапливайте через `res -= res / p`, а не умножением $n$ на дробь.
