# Модулярная арифметика

**Модулярная арифметика** — все вычисления по модулю $m$: результат приводится к остатку $[0, m-1]$. Это стандарт олимпиадных задач: ответ огромен, а выдать нужно остаток от деления на простое $10^9 + 7$ (или $10^9 + 9$).

* **Сложение и умножение по модулю:** всегда «в безопасной зоне», если аккуратно с `long long`.
* **Вычитание по модулю:** после вычитания прибавляем `mod` — иначе уйдём в минус.
* **Быстрое возведение в степень:** $O(\log n)$ вместо $O(n)$.
* **Обратный элемент** $a^{-1} \bmod m$: существует $\iff \gcd(a, m) = 1$; при простом $m$ — через малую теорему Ферма.

---

## 🛠️ Идея и готовый шаблон

Вся арифметика замыкается на модуле: `(a + b) % mod`, `(a * b) % mod`. Главная опасность — переполнение до взятия модуля: `int * int` легко уходит за $2^{31}$, поэтому умножение — в `long long`.

```cpp
#include <bits/stdc++.h>

using namespace std;

using ll = long long;

const ll MOD = 1'000'000'007;

ll add(ll a, ll b) { return (a + b) % MOD; }

ll sub(ll a, ll b) { return (a - b + MOD) % MOD; } // + MOD: не уходим в минус

ll mul(ll a, ll b) { return (a * b) % MOD; }       // влияет в long long
```

> [!⚠️] Переполнение умножения
> `(a * b) % MOD` с `int`-аргументами — классический баг: $10^9 \cdot 10^9$ не влезает в `int`. Всегда кастите к `long long` (или используйте `ll` в сигнатурах, как выше). Если `mod` больше $10^9$ — даже `long long` может переполниться, тогда `__int128` или `mulmod` через сдвиги.

## 💻 Быстрое возведение в степень

Хотим $a^n \bmod m$. Используем двоичное разложение показателя: $a^n = a^{n_0} \cdot (a^2)^{n_1} \cdot (a^4)^{n_2} \cdot \dots$ — каждая степень возводится в квадрат, а перемножаются только те, где бит показателя $= 1$.

```cpp
ll binpow(ll a, ll n, ll mod = MOD) {
    a %= mod;
    ll res = 1;
    while (n) {
        if (n & 1) res = mul(res, a);
        a = mul(a, a);   // квадрат текущей степени
        n >>= 1;
    }
    return res;
}
```

* **Сложность:** $O(\log n)$ — примерно 60 итераций для $n \le 10^{18}$.
* Обращает внимание: при $n = 0$ возвращает $1$ — это корректная база.

## 💻 Обратный элемент

Обратный к $a$ по модулю $m$ — такое $x$, что $a \cdot x \equiv 1 \pmod m$. Способы в порядке предпочтения:

* **Модуль простой** → малая теорема Ферма: $a^{m-1} \equiv 1 \pmod m$, значит $a^{-1} = a^{m-2} \bmod m$. Один `binpow`.
* **Модуль составной, но $\gcd(a, m) = 1$** → [[Расширенный алгоритм Евклида]]: $ax + my = 1$, тогда $x$ и есть обратный.
* **Для всех чисел от $1$ до $n$ за раз** — рекуррента $inv[i] = (mod - mod/i) \cdot inv[mod \% i] \% mod$, $O(n)$.

```cpp
ll modInvPrime(ll a, ll mod = MOD) { // mod — простое
    return binpow(a, mod - 2, mod);
}

// Все обратные по простому модулю за O(n)
vector<ll> inverses(int n, ll mod) {
    vector<ll> inv(n + 1);
    inv[1] = 1;
    for (int i = 2; i <= n; i++)
        inv[i] = (mod - mod / i) * inv[mod % i] % mod;
    return inv;
}
```

> [!⚠️] Обратный не всегда существует
> Ищите $a^{-1} \bmod m$ только при $\gcd(a, m) = 1$. Иначе задача не имеет решения — это обычная ловушка: «нули» в знаменателях формул (например, в сочетаниях по составному модулю) нельзя наивно обращать.

## 🔍 Где применяется

| Задача                                        | Решение через                                  |
| :-------------------------------------------- | :--------------------------------------------- |
| Любой «огромный ответ по модулю»              | Модулярный шаблон `add/sub/mul`                |
| $a^n \bmod m$, $n$ до $10^{18}$               | `binpow`, $O(\log n)$                          |
| Комбинаторика по модулю                       | Факториалы + обратные элементы (см. [[Комбинаторика]]) |
| Деление по модулю                             | Умножение на обратный элемент                  |
| Матричные перемножения по модулю              | `mul` внутри умножения матриц                  |

## 🔍 Нюансы

* **Отрицательные остатки:** `%` в C++ возвращает остаток со знаком делимого: `-3 % MOD` отрицателен. Нормализуйте: `((x % MOD) + MOD) % MOD`.
* **Не увлекайтесь `%` в цикле:** `x % MOD` на каждой итерации дорог; где можно, накапливайте в `long long` и приводите к модулю по факту.
* **Приоритет:** перемножение трёх чисел по модулю — делайте по два: `mul(mul(a, b), c)`, иначе переполнение.
* **Связки:** обратный элемент — фундамент [[Комбинаторика]]; расширенный Евклид для составных модулей — [[Расширенный алгоритм Евклида]]; предподсчёт по решету — [[Функция Эйлера]] (по ней считается обратный и для составного $m$).
