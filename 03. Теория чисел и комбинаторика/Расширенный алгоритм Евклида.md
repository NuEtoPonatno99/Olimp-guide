# Расширенный алгоритм Евклида

**Расширенный алгоритм Евклида** находит не только $\gcd(a, b)$, но и коэффициенты $x, y$ в соотношении **$ax + by = \gcd(a, b)$**. Отсюда — решение линейных диофантовых уравнений $ax + by = c$ и обратный элемент по составному модулю.

* **Сложность:** $O(\log \min(a, b))$ — та же, что у обычного [[НОД и НОК|Евклида]].
* **Выход:** тройка $(g, x, y)$, где $g = \gcd(a, b)$, $ax + by = g$.
* **Уравнение $ax + by = c$ разрешимо $\iff \gcd(a, b) \mid c$.**
* **Без него не работает** [[Китайская теорема об остатках]] для непопарно взаимно простых модулей.

---

## 🛠️ Идея

Обычный Евклид: $\gcd(a, b) = \gcd(b, a \% b)$. Расширенный тащит за этим **обратный проход**: пока раскручиваем рекурсию, пересобираем коэффициенты. На шаге, где уже посчитано $b x' + (a \% b) y' = g$, подставляем $a \% b = a - \lfloor a/b \rfloor \cdot b$ и перекладываем коэффициенты:

$$ax + by = b x' + (a \% b) y' = b x' + (a - \lfloor a/b \rfloor b) y' = a \cdot y' + b \cdot (x' - \lfloor a/b \rfloor y')$$

Значит переход: `x = y'`, `y = x' - (a / b) * y'`. На базе `b == 0`: $a \cdot 1 + 0 \cdot 0 = a$, то есть `(a, 1, 0)`.

```cpp
#include <iostream>

using namespace std;

using ll = long long;

// Возвращает (g, x, y): g = gcd(a,b), a*x + b*y = g
ll egcd(ll a, ll b, ll& x, ll& y) {
    if (b == 0) { x = 1; y = 0; return a; }
    ll x1, y1;
    ll g = egcd(b, a % b, x1, y1);
    x = y1;
    y = x1 - (a / b) * y1;
    return g;
}

int main() {
    ll a = 30, b = 12, x, y;
    ll g = egcd(a, b, x, y);
    cout << "gcd = " << g << ", x = " << x << ", y = " << y << endl;
    cout << "проверка: " << a * x + b * y << endl; // должно быть g
    return 0;
}
```

## 💻 Линейное диофантово уравнение $ax + by = c$

Из $ax_0 + by_0 = g$ получаем одно частное решение $x = x_0 \cdot (c / g)$, $y = y_0 \cdot (c / g)$ — но если $c$ не делится на $g$, решений нет. Все решения различаются на шаг по НОК:

$$x = x_0 \cdot \frac{c}{g} + k \cdot \frac{b}{g}, \qquad y = y_0 \cdot \frac{c}{g} - k \cdot \frac{a}{g}, \qquad k \in \mathbb{Z}$$

Шаг $\frac{b}{g}$ (для $x$) — ровно минимальный сдвиг, сохраняющий целые решения. Часто просят «решение с минимальным неотрицательным $x$» — приводите переменной $x$ к нужной полосе через `%`:

```cpp
ll solveDiophantine(ll a, ll b, ll c, ll& x, ll& y) {
    ll g = egcd(a, b, x, y);
    if (c % g != 0) return -1;          // нет решений
    x *= c / g;
    y *= c / g;
    ll step = b / g;                    // шаг по x
    // минимальное неотрицательное x: сдвигаем на кратное шага
    x = (x % step + step) % step;
    y = (c - a * x) / b;                // пересчитываем y под новый x
    return g;
}
```

> [!⚠️] Знаки `a` и `b`
> Евклид обычно ждёт неотрицательные числа, а в решении могут быть отрицательные коэффициенты. Домножайте обе части на $-1$ так, чтобы `a` и `b` были положительными, решайте, затем возвращайте знак в ответе. Проверяйте результат подстановкой в исходное уравнение.

## 💻 Обратный элемент по составному модулю

Для $a^{-1} \bmod m$ при $\gcd(a, m) = 1$ решаем $ax + my = 1$: тогда $x$ и есть обратный (приводим в диапазон $[0, m-1]$). Это работает и для непростого $m$ — в отличие от малой теоремы Ферма из [[Модулярная арифметика]].

```cpp
ll modInverse(ll a, ll m) {
    ll x, y;
    ll g = egcd(a, m, x, y);
    if (g != 1) return -1;          // обратного нет: a и m не взаимно просты
    return (x % m + m) % m;         // нормализуем в [0, m-1]
}
```

## 🔍 Где применяется

| Задача                                        | Решение через                                    |
| :-------------------------------------------- | :----------------------------------------------- |
| Решения $ax + by = c$                         | Расширенный Евклид, проверка $g \mid c$          |
| Обратный элемент по составному модулю         | $ax + my = 1$                                    |
| Нормализация дробей по модулю                 | Умножение на обратный (см. [[Модулярная арифметика]]) |
| Системы сравнений с непопарно простыми модулями | [[Китайская теорема об остатках]] + слияние сравнений |
| НОД и НОК базово                             | Обычный [[НОД и НОК\|Евклид]]                    |

## 🔍 Нюансы

* **Знак quotient на С++:** `a / b` округляет к нулю, а вся теория пишется для положительных — приводите аргументы к положительным до вызова.
* **Переполнение в `y = x1 - (a / b) * y1`:** коэффициенты могут расти до самих чисел — берите `long long`.
* **Отсутствие решений:** при $g \nmid c$ система не имеет решений вообще — проверяйте до умножения, иначе получите чепуху.
* **Классическая связка:** расширенный Евклид — это основа CRT: без него не склеить несколько сравнений в одно.
