# НОД и НОК

**НОД** ($\gcd$, наибольший общий делитель) — наибольшее число, на которое делятся оба числа. **НОК** (наименьшее общее кратное) — наименьшее положительное число, делящееся на оба. Считаются алгоритмом Евклида за $O(\log \min(a, b))$.

* **Сложность алгоритма Евклида:** $O(\log \min(a, b))$ — после каждого шага параметры минимум вдвое уменьшаются.
* **C++ готовое:** `std::gcd` / `std::lcm` из `<numeric>` (C++17).
* **Ключевая формула:** $\text{НОК}(a, b) = \dfrac{a \cdot b}{\text{НОД}(a, b)}$ — считайте в `long long`, чтобы не переполниться.
* **Расширенный вариант**, дающий ещё и коэффициенты $x, y$ для $ax + by = \gcd$ — отдельная тема [[Расширенный алгоритм Евклида]].

---

## 🛠️ Идея

Алгоритм Евклида: $\gcd(a, b) = \gcd(b, a \% b)$, пока $b \ne 0$. Интуиция: любой общий делитель `a` и `b` делит и их разность, поэтому `a % b` сохраняет весь набор общих делителей.

```cpp
#include <iostream>
#include <numeric>  // std::gcd, std::lcm

using namespace std;

// Классика через рекурсию
long long gcdRec(long long a, long long b) {
    return b == 0 ? a : gcdRec(b, a % b);
}

// Итеративно — без стека
long long gcdIter(long long a, long long b) {
    while (b) {
        long long t = a % b;
        a = b;
        b = t;
    }
    return a;
}

long long lcm(long long a, long long b) {
    return a / gcdIter(a, b) * b; // делим ДО умножения, чтобы не переполниться
}

int main() {
    long long a = 48, b = 18;
    cout << "НОД = " << gcdRec(a, b) << " (встроенный: " << std::gcd(a, b) << ")\n";
    cout << "НОК = " << lcm(a, b) << endl; // 144
    return 0;
}
```

* `a / gcd * b` вместо `a * b / gcd` — замена на умножение после деления убирает переполнение.
* `std::gcd` вернёт положительное значение даже для отрицательных аргументов.

## 💻 Бинарный алгоритм (без деления)

Делению `%` на больших числах предпочитают сдвиги и вычитания. Бинарный НОД использует чётность:

* оба чётные: $\gcd(a, b) = 2 \cdot \gcd(a/2, b/2)$;
* одно чётное: $\gcd(a, b) = \gcd(a/2, b)$;
* оба нечётные: $\gcd(a, b) = \gcd(a - b, b)$.

```cpp
#include <iostream>

using namespace std;

long long gcdBinary(long long a, long long b) {
    if (a == 0) return b;
    if (b == 0) return a;

    int shift = 0;
    while (((a | b) & 1) == 0) { a >>= 1; b >>= 1; shift++; } // общая степень двойки

    while ((a & 1) == 0) a >>= 1; // теперь a нечётное

    do {
        while ((b & 1) == 0) b >>= 1; // сделать b нечётным
        if (a > b) swap(a, b);
        b -= a;                       // разность чётная, следующая итерация её делит
    } while (b != 0);

    return a << shift; // вернуть вынесенную степень двойки
}

int main() {
    cout << gcdBinary(48, 18) << endl; // 6
    return 0;
}
```

> [!⚠️] Когда бинарный НОД реально нужен
> На обычных 64-битных числах `std::gcd` быстрее. Бинарный выигрывает на числах произвольной длины (BigInt), где деление стоит дорого. Для олимпиадного C++ достаточно запомнить его существование.

## 🔍 Где применяется

| Задача                                        | Решение через                                    |
| :-------------------------------------------- | :----------------------------------------------- |
| `НОД` / `НОК` двух чисел                      | Евклид или `std::gcd`, $\text{НОК} = a/g \cdot b$ |
| НОД на подотрезке, много запросов             | [[Дерево отрезков]] / sparse table               |
| Сокращение дроби `p/q`                        | Поделить оба на НОД                              |
| НОД всех чисел массива через префиксы         | Префиксные НОД: свойство «меняется $O(\log)$ раз» |
| Решение линейного диофантова уравнения        | [[Расширенный алгоритм Евклида]]                  |
| Период повторения последовательностей         | НОД периодов, «минимум через НОК»                |

## 🔍 Нюансы

* **НОК ломается на переполнении:** пишите `a / gcd * b`, берите `long long`.
* **НОД нуля:** $\gcd(a, 0) = a$, это корректная база рекурсии.
* **Отрицательные числа:** НОД обычно полагают положительным; `std::gcd` гарантирует неотрицательный результат, с минусом справляйтесь сами.
* **Связка с [[Модулярная арифметика]]:** НОД нужен, чтобы проверить, существует ли обратный элемент по модулю $m$ — он есть тогда и только тогда, когда $\gcd(a, m) = 1$.
