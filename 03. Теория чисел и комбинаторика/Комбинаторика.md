# Комбинаторика

**Комбинаторика** — подсчёт количества способов. На практике: **сочетания** $C(n, k) = \binom{n}{k}$, **Каталановы числа**, **принцип включения-исключения** и формулы по модулю (обычно простому, типа $10^9 + 7$).

* **База модулярной комбинаторики:** факториалы + обратные элементы (см. [[Модулярная арифметика]]) для $C(n, k)$ за $O(1)$ после $O(n)$ предподсчёта, или треугольник Паскаля за $O(nk)$.
* **Лукас:** для больших $n$ и простого модуля $p$: $\binom{n}{k} \equiv \binom{n \bmod p}{k \bmod p} \binom{\lfloor n/p \rfloor}{\lfloor k/p \rfloor} \pmod p$.
* **Каталан:** $C_n = \dfrac{1}{n+1}\binom{2n}{n}$ — число правильных скобочных последовательностей и многого другого.
* **Включение-исключение:** $|\cup A_i| = \sum|A_i| - \sum|A_i \cap A_j| + \dots$ — «минус пересечения, такова цена счёта вслепую».

## 🛠️ Сочетания по модулю: факториалы

Считаем факториалы и обратные к ним один раз, потом любое сочетание за $O(1)$:

$$C(n, k) = \frac{n!}{k! \, (n-k)!} \bmod MOD$$

```cpp
#include <bits/stdc++.h>

using namespace std;

using ll = long long;

const ll MOD = 1'000'000'007;
const int MAXN = 1'000'000;

vector<ll> fact, invFact;

ll binpow(ll a, ll e) {
    a %= MOD;
    ll r = 1;
    while (e) { if (e & 1) r = r * a % MOD; a = a * a % MOD; e >>= 1; }
    return r;
}

void precompute() {
    fact.resize(MAXN + 1);
    invFact.resize(MAXN + 1);
    fact[0] = 1;
    for (int i = 1; i <= MAXN; i++) fact[i] = fact[i - 1] * i % MOD;
    invFact[MAXN] = binpow(fact[MAXN], MOD - 2); // одно возведение в степень
    for (int i = MAXN; i >= 1; i--) invFact[i - 1] = invFact[i] * i % MOD; // и обратный проход
}

ll C(ll n, ll k) {
    if (k < 0 || k > n) return 0;
    return fact[n] * invFact[k] % MOD * invFact[n - k] % MOD;
}
```

* `invFact` получаем **одним** возведением в степень + обратным проходом: `invFact[i-1] = invFact[i] * i`.
* Если нужен только маленький $n$ — дешевле треугольник Паскаля: `dp[i][j] = dp[i-1][j-1] + dp[i-1][j]`.

> [!⚠️] Когда модуль не простой
> Делить через обратный элемент можно только по простому модулю. Для составного $MOD$ сочетания считают иначе: факторизация $MOD$, вычисление по его простым степеням и CRT (см. [[Китайская теорема об остатках]]). Либо Паскалем, если $n$ мало.

## 💻 Лукас: большие $n$

Теорема Лукаса сводит задачу с гигантским $n$ к сочетаниям с медленным модулем $p$ (по цифрам в $p$-ичной записи):

```cpp
ll Csmall(ll n, ll k, ll p) { // n, k < p: обычные факториалы по простому p
    if (k > n) return 0;
    /* fact/invFact по модулю p, см. выше */
    return fact[n] * invFact[k] % p * invFact[n - k] % p;
}

ll lucasC(ll n, ll k, ll p) {
    ll res = 1;
    while (n || k) {
        res = res * Csmall(n % p, k % p, p) % p; // берём по последней цифре
        n /= p;                                  // и сдвигаем «на цифру влево»
        k /= p;
    }
    return res;
}
```

* Работает для $n, k$ до $10^{18}$ при небольшом простом $p$: циклов-цифр ~ $O(\log_p n)$.
* `Csmall` требует модуль простым — p-и там факториалы считаются заново по каждому $p$ (или кэшируются).

## 💻 Каталан и включение-исключение

**Числа Каталана** $C_n = \frac{1}{n+1}\binom{2n}{n}$ считают: правильные скобочные последовательности, треугольные разбиения, способы обхода лестницы, бинарные деревья.

```cpp
ll catalan(ll n) { return C(2 * n, n) * binpow(n + 1, MOD - 2) % MOD; } // деление = на обратный
```

**Включение-исключение** — сила для задач «хотя бы одно из условий». Если нужно посчитать объекты без запрещённых свойств, берём $всё$ и вычитаем с чередующимися знаками пересечения множеств подмножеств:

```cpp
// Пример: число перестановок длины n, где НИ ОДИН элемент не стоит на месте (беспорядки)
ll derangements(int n) {
    ll res = 0;
    for (int k = 0; k <= n; k++) {
        ll term = C(n, k) * fact[n - k] % MOD; // фиксируем k позиций «на своих местах»
        if (k & 1) res = (res - term + MOD) % MOD; // знак чередуется
        else       res = (res + term) % MOD;
    }
    return res;
}
```

> [!⚠️] Перебор подмножеств для включения-исключения
> Когда свойств немного ($k \le 20$), по ним бегает перебор битмасками `for (int mask = 0; mask < (1 << k); mask++)`: знак — чётность `popcount(mask)`. См. [[ДП по подмножествам (битмаски)]].

## 🔍 Где применяется

| Задача                                        | Решение через                                            |
| :-------------------------------------------- | :------------------------------------------------------- |
| Число способов выбрать $k$ из $n$             | Факториалы + обратные, $C(n,k)$ за $O(1)$                |
| Большие $n$, простой модуль                   | Теорема Лукаса                                           |
| Составной модуль                              | Примарные модули + [[Китайская теорема об остатках]]     |
| Скобки, деревья, разбиения                    | Каталан: $C_n = \binom{2n}{n}/(n+1)$                     |
| «Ни одного из плохих событий»                 | Включение-исключение (беспорядки, простые подмножества)  |
| Перебор всех подмножеств для вкл.-искл.       | Битмаски, $O(2^k)$                                       |

## 🔍 Нюансы

* **Симметрия:** $C(n, k) = C(n, n-k)$ — считайте по меньшей из $k$ и $n-k$ (меньше работы, меньше переполнения в факториалах).
* **Граница `k > n`:** в `C()` обязана вернуть $0$, а не «падение по индексу» в массиве.
* **Деление в Каталане** — через обратный элемент `binpow(n + 1, MOD - 2)`, а не целочисленное деление: всё живёт по модулю.
* **Лукас требует простой модуль:** для составного он неверен; там либо CRT-путь, либо маленький Паскаль.
* **Знаки вкл.-искл.:** `+` для пустого пересечения, дальше знак = $(-1)^{\text{размер}}$. Ошибка в знаке — классика, проверяйте на $n = 1$.
