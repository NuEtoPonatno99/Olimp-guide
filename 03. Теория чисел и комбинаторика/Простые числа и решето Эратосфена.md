# Простые числа и решето Эратосфена

**Простые числа** — натуральные числа больше $1$, делящиеся только на $1$ и на себя. Чтобы быстро получить все простые до $n$ и их свойства, используется **решето Эратосфена** и его улучшенная версия — **линейное решето** с массивом `spf` (наименьший простой делитель).

* **Сложность решета Эратосфена:** $O(n \log \log n)$ по времени и $O(n)$ по памяти.
* **Сложность линейного решета:** $O(n)$ — каждое число вычёркивается ровно один раз.
* **SPF-факторизация:** с массивом `spf` любое число раскладывается на множители за $O(\log n)$, а не за $O(\sqrt n)$.
* **C++ готовое:** проверка одного числа за $O(\sqrt n)$ — вручную; готового решета в STL нет.

---

## 🛠️ Идея

Проверка одного числа перебором делителей до $\sqrt n$ — самая базовая техника:

```cpp
#include <bits/stdc++.h>

using namespace std;

bool isPrime(long long x) {
    if (x < 2) return false;
    for (long long d = 2; d * d <= x; d++)
        if (x % d == 0) return false;
    return true;
}
```

Но когда нужно **много** простых чисел подряд — решето. Классика: массив `isPrime`, где вычёркиваем кратные каждого найденного простого. Кратные можно начинать с `p * p` — всё, что меньше, уже вычеркнуто меньшими простыми.

```cpp
// Все простые до n включительно. Превращает isPrime[p] = true в решето
vector<bool> sieve(int n) {
    vector<bool> isPrime(n + 1, true);
    isPrime[0] = isPrime[1] = false;
    for (int p = 2; p * 1LL * p <= n; p++) {
        if (isPrime[p]) {
            for (int x = p * p; x <= n; x += p)     // начинаем с p*p!
                isPrime[x] = false;
        }
    }
    return isPrime;
}
```

* Решето обрабатывает только внутренний цикл простых $p$: вычёркиваний примерно $n \sum \frac{1}{p} = n \log \log n$.
* `p * 1LL * p` — защита от переполнения `int` при проверке `p * p <= n`.

## 💻 Линейное решето и SPF

У классического решета проблема: число вычёркивается несколько раз (например, $12$ помечают и $2$, и $3$). Линейное решето строит каждое число **один раз**, попутно запоминая его `spf` — наименьший простой делитель:

```cpp
const int N = 1'000'000;
vector<int> primes;        // все простые до N
vector<int> spf(N + 1, 0); // spf[x] = наименьший простой делитель x

void linearSieve() {
    for (int i = 2; i <= N; i++) {
        if (spf[i] == 0) {        // i оказалось простым
            spf[i] = i;
            primes.push_back(i);
        }
        // каждое составное i*p вычёркиваем ровно один раз
        for (int p : primes) {
            if (p > spf[i] || 1LL * i * p > N) break;
            spf[i * p] = p;
        }
    }
}

// Факторизация за O(log n): делим число на его spf пока не останется 1
void factorize(int x) {
    while (x > 1) {
        int p = spf[x], cnt = 0;
        while (x % p == 0) { x /= p; cnt++; }
        cout << p << "^" << cnt << " ";
    }
    cout << endl;
}
```

> [!⚠️] Зачем нужен `p > spf[i]`
> Внутренний цикл обязан остановиться, как только простое `p` превысит `spf[i]`. Иначе число $i \cdot p$ вычеркнется ещё раз другим путём — это разрушает линейность. Правило: **наименьший простой множитель `i*p` должен быть ровно `p`**, а это верно только пока `p <= spf[i]`.

## 🔍 Где применяется

| Задача                                        | Решение через                                               |
| :-------------------------------------------- | :---------------------------------------------------------- |
| Все простые до $n$                            | Решето Эратосфена, $O(n \log \log n)$                       |
| $k$-е простое, «следующее простое»            | Линейное решето с массивом `primes`                          |
| Факторизация числа на множители               | `spf`-решето за $O(\log n)$ на число                        |
| Количество делителей / сумма делителей        | Факторизация + комбинаторика по показателям                  |
| Ответы, зависящие от простоты чисел           | `isPrime`-массив для всех чисел до $n$                       |

## 🔍 Нюансы

* **`spf` экономит время в задачах на модуль:** предподсчитали `spf` один раз за $O(n)$ — факторизуем сколько угодно чисел за $O(\log n)$ вместо $O(\sqrt n)$.
* **Память:** `vector<bool>` компактнее `vector<char>`/`vector<int>` (по 1 биту на элемент), но медленнее. Для `spf` нужен `int`.
* **Перебор до $\sqrt n$:** суммарно по всем числам до $n$ это $O(n \sqrt n)$ — решето всегда выигрывает при массовых проверках.
* **Решето тесно связано с [[Функция Эйлера]]:** её значения считаются решетом той же техникой, а [[Модулярная арифметика]] использует простоту для обратного элемента.
* **$O(n \log \log n)$ практически линейное:** при $n = 10^7$ решето отрабатывает за доли секунды, лимит — только память.
