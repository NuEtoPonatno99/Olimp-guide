# Сканирующая прямая

**Сканирующая прямая (line sweep)** — сведение задачи к проходу по **событиям**, отсортированным по одной координате. Двигаем «прямую» слева направо и поддерживаем текущее состояние; при событии состояние меняется. Так площадь объединения прямоугольников, максимум наложений отрезков и многие оффлайн-задачи решаются за $O(n \log n)$.

* **Шаблон:** «события» (начало/конец) → сортировка по координате → проход с обновлением состояния.
* **В геометрии** работает с [[Точка, прямая, отрезок]] и [[Векторы]]; **в структурах** состояние часто — [[Дерево отрезков]].
* **Классика:** площадь объединения прямоугольников — sweep по $x$ + дерево отрезков по сжатым $y$.
* Простейший случай — «максимум наложений интервалов» — вообще без дерева.

---

## 🛠️ Идея: события вместо инварианта

Прямая заметает плоскость слева направо. Всё, что нужно знать в момент $x$, — «текущее состояние»: какие отрезки открыты, какие рёбра активны. Меняется оно **только в координатах событий**; между событиями ничего не происходит.

Типичное событие — пара «координата, действие»:

- `+1` на начале отрезка / на левом ребре прямоугольника;
- `-1` на его конце.

Сортируем события по координате и проходим: состояние меняем на лету, агрегат (максимум, длина покрытия, площадь) обновляем сразу. Асимптотика — сортировка плюс стоимость обновлений.

## 💻 Максимум наложений интервалов

Задача «сколько максимум отрезков покрывают одну точку» — разогрев техники:

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int maxOverlap(const vector<pair<int, int>>& segs) {
    vector<pair<int, int>> ev;  // (координата, +1 на старте, -1 после конца)
    for (auto& s : segs) {
        ev.push_back({s.first, +1});
        ev.push_back({s.second + 1, -1});   // закрываем ПЕРЕД s.second + 1
    }
    sort(ev.begin(), ev.end());

    int cur = 0, best = 0;
    for (auto& e : ev) {
        cur += e.second;
        best = max(best, cur);
    }
    return best;
}
```

* Отрезок $[l, r]$ включительно: конец ставим в `r + 1`, чтобы не закрыть его раньше времени.
* События с одинаковой координатой обрабатываются подряд — сортировка это гарантирует; максимум считываем после применения всех.

## 💻 Площадь объединения прямоугольников

Вертикальные стороны прямоугольников — события `(x, y1, y2, ±1)`. По $y$ идёт [[Дерево отрезков]], хранящее **суммарную длину покрытых отрезков**; площадь полосы между соседними событиями = длина покрытия × ширина полосы:

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;
using ll = long long;

struct Event { ll x, y1, y2; int type; };   // type = +1: открытие, -1: закрытие

struct SegTreeByY {
    vector<ll> coord;          // сжатые y
    vector<int> cover;         // счётчик покрытий
    vector<ll> len;            // длина покрытой части
    int sz;

    SegTreeByY(const vector<ll>& ys) : coord(ys), sz((int)ys.size() - 1) {
        cover.assign(4 * sz, 0);
        len.assign(4 * sz, 0);
    }

    void upd(int v, int l, int r, int ql, int qr, int val) {
        if (ql >= r || qr <= l) return;
        if (ql <= l && r <= qr) {
            cover[v] += val;
        } else {
            int m = (l + r) / 2;
            upd(v * 2, l, m, ql, qr, val);
            upd(v * 2 + 1, m, r, ql, qr, val);
        }
        len[v] = cover[v] ? coord[r] - coord[l]
                          : (r - l == 1 ? 0 : len[v * 2] + len[v * 2 + 1]);
    }

    ll covered() const { return len[1]; }
};

ll unionArea(vector<Event>& ev, vector<ll>& ys) {
    // сжатие y
    sort(ys.begin(), ys.end());
    ys.erase(unique(ys.begin(), ys.end()), ys.end());
    sort(ev.begin(), ev.end(), [](const Event& a, const Event& b) { return a.x < b.x; });

    SegTreeByY st(ys);
    ll area = 0, prevX = ev[0].x;
    for (auto& e : ev) {
        area += st.covered() * (e.x - prevX);   // полоса между двумя событиями
        int l = lower_bound(ys.begin(), ys.end(), e.y1) - ys.begin();
        int r = lower_bound(ys.begin(), ys.end(), e.y2) - ys.begin();
        st.upd(1, 0, st.sz, l, r, e.type);      // открыть / закрыть y-отрезок
        prevX = e.x;
    }
    return area;
}
```

* Каждый прямоугольник `(x1, y1, x2, y2)` даёт два события: `ev.push_back({x1, y1, y2, +1})` и `ev.push_back({x2, y1, y2, -1})`.
* Сжатие координат: узлы дерева — **полуинтервалы** `[coord[i], coord[i+1])`, поэтому `(y1, y2)` отображается в диапазон индексов.
* `cover[v] > 0` — вершина целиком покрыта → длина `coord[r] - coord[l]`; иначе длина равна сумме детей.
* Сложность: $O(n \log n)$; у событий с одинаковым $x$ ширина полосы нулевая — площадь не «накапливается».

## 🧮 Где применяется

| Задача                                              | Состояние при sweep                                |
| :-------------------------------------------------- | :------------------------------------------------- |
| Максимум наложений интервалов / точек покрытия      | счётчики `+1/-1`                                   |
| Площадь объединения прямоугольников                 | [[Дерево отрезков]] по сжатым $y$                  |
| Ближайшая пара точек (оффлайн)                      | активная полоса около текущего $x$                 |
| Пересечения отрезков                                | BST активных отрезков с порядком по $y$            |
| Горизонт / видимость рёбер многоугольника           | стек активных рёбер                                |
| Оффлайн-ответы «сколько точек в интервале $(a, b]$» | события точек и концов интервалов                  |

## 🔍 Нюансы

* **Инклюзивность границ:** `[l, r]` vs `[l, r)` — определяет, куда ставить `-1`; ошибка на границе — классика.
* **Совпадение координат:** все события с одной абсциссой применяются до обновления агрегатов между полосами.
* **Сжатие координат** обязано быть отсортированным и уникальным; полуинтервалы убирают двойной счёт рёбер.
* **Типы:** координаты и площади — `long long`, произведение сторон легко бьёт `int`.
* **Вещественные события:** если `x` типа `double`, приоритет типов событий на одной абсциссе задавайте явно — тех же приёмов, что в [[Точка, прямая, отрезок]].
